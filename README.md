# mangacli

mangacli renders Japanese-style manga pages from a structured description. You write the page layout, panels, speech balloons, dialogue, and effects in YAML (or build the same structure as a TypeScript object), and mangacli outputs finished page images in black-and-white or color.

You supply the artwork (characters, backgrounds) as image files. mangacli draws everything else: panel borders, speech balloons, typeset dialogue, hand-lettered sound effects, focus lines and other effect lines, screentones, and manpu marks. All of it is drawn to look **hand-inked**: balloons wobble slightly, lines taper and vary with pen pressure, and closed outlines don't meet perfectly.

## Features

- Japanese manga conventions by default: right-to-left reading, vertical text, mixed antique/gothic fonts (アンチゴチ), ruby, emphasis dots, tate-chu-yoko, kinsoku line breaking, gutters, bleed panels, page numbers.
- Balloons in many styles: ellipse, thought cloud, shout spikes, scream burst, trembling, whisper (dashed), narration box, electronic voice, inverted, connected balloons. Tails aim at the speaker's mouth and stop short of the face; off-panel speakers get tails cut by the frame. Balloons are sized to the text and placed automatically in reading order, avoiding faces and figures.
- Effects: focus lines, beta flash, uni flash, speed lines, gloom lines, swirl lines, rain, hatching, kakeami, impact, vignette, contour-following flame auras and lightning arcs, and screentones (dots, lines, noise, gradient tones).
- Sound effects with per-character rotation, growth, warping, roughening, and outlines; manpu marks such as sweat, anger veins, sparkles, and hearts.
- Output as PNG, JPEG, WebP, AVIF, TIFF, SVG, or PDF (with trim and bleed boxes), optionally with crop marks. Color, grayscale, or 1-bit monochrome for print (600 dpi B5 by default), with bleed and separations.
- Deterministic: the same input always produces the same output. Change the seed to get a "redrawn" take.
- Japanese fonts are fetched on demand from a built-in catalog of SIL OFL fonts (pinned and hash-verified), so pages render without any font setup.
- Diagnostics point to the YAML line and column, with hints.
- Extensible with plugins: balloon shapes, effects, marks, pens, layout templates, page sizes, styles, and processing hooks.
- Both a CLI (with a live preview server) and a TypeScript API.

## Quick start

Requires Node.js 24 or later.

```bash
npm install --save-dev mangacli
npx mangacli init my-manga        # creates manga.yaml, a config file, and fetches fonts
cd my-manga
npx mangacli render manga.yaml    # writes out/manga-001.png
```

The template uses placeholders instead of artwork, so it renders right away. Put your images in `assets/` and point `image:` at them.

## A taste of the format

```yaml
mangacli: 1

assets:
  taro: ./assets/taro.png

pages:
  - layout:
      rows: [[1], [1, 1]]
    panels:
      - layers:
          - image: taro
          - balloon: おはよう
      - layers:
          - balloon: |
              今日は
              いい天気だね
      - layers:
          - effect: focus-lines
          - text: その時——
            place: top-right
```

Add `# yaml-language-server: $schema=./node_modules/mangacli/schema.json` at the top of the file for completion and validation in editors.

## CLI

```bash
mangacli render <file> [-p print-mono|print-gray|print-color|web|sns|preview|draft] [-o out] [--pages 1-3]
mangacli validate <file> [--strict] [--reporter text|json|github]
mangacli watch <file>                  # re-render on save
mangacli preview <file> [--open] [--guides] # live preview in the browser (127.0.0.1:4173)
mangacli init [dir] [--template basic|b5-mono|sns-color|yonkoma]
mangacli fonts install [--set manga-basic] [--for manga.yaml] [--dir ./fonts]
mangacli fonts list [--catalog]
mangacli schema [--out schema.json]
mangacli transcript <file> [--format md|json|txt]
mangacli inspect <file> [--layout] [--resolved] [--page p1]
mangacli fonts verify | fonts licenses [file]
mangacli cache info | cache clean
```

In live preview, click an element warning to locate it with a highlight frame. Click again or press Esc to clear; selection survives auto-reload independently of Guides.

Run `mangacli <command> --help` for all options. `--json` prints machine-readable NDJSON.

For PDF/X submission, ask your printer for the version and CMYK ICC profile. For example:

```bash
mangacli render manga.yaml -p print-mono -f pdf --pdf-x 4 \
  --pdf-x-icc printer.icc --pdf-x-condition "Printer's output condition"
```

Use `--pdf-x 1a` for PDF/X-1a:2001 (ICC v2 only). Both modes keep the page raster 1-bit monochrome on the black plate. Without these flags, PDF output is unchanged. Run the printer's own preflight before submission.

## API

```ts
import { render } from "mangacli";

const result = await render("./manga.yaml", { profile: "print-mono", outDir: "./out" });
for (const d of result.diagnostics) console.warn(d.code, d.message);
```

`render` also accepts a YAML string (`{ yaml }`) or a document object, and returns the encoded images when `outDir` is omitted. See [docs/11-api.md](docs/11-api.md).
