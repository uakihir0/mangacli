# 7. 文字と組版

## 7.1 文字を扱う要素

| 要素 | 用途 | 既定の組み方 | 既定のフォントロール |
|---|---|---|---|
| `balloon` の本文 | セリフ | 写植（揺らぎなし） | `as` による（[6.13](06-balloons.md#613-組み込みスタイル)） |
| `text` | ナレーション、注釈、手書き文字、題 | 写植 | `narration` |
| `sfx` | 擬音・擬態語の描き文字 | 手書き風（変形・揺らぎあり） | `sfx` |
| ノンブル | ページ番号 | 写植 | `ui` |

商業漫画の吹き出しのセリフは写植であり、文字そのものは揺らがない。本ライブラリもこれを既定とし、手書きらしさは吹き出しの線で表現する。手書き文字が必要な場合は `lettering: hand` を指定する（[7.15](#715-手書き風の文字)）。

## 7.2 組版のプロパティ

`balloon`、`text`、`sfx` に共通する。

| キー | 型 | 既定値 | 説明 |
|---|---|---|---|
| `font` | フォント名 \| ロール名 | 要素による（7.1） | フォント（[7.3](#73-フォント)） |
| `fontSize` | Length | 吹き出し 13 Q、`text` 12 Q、`sfx` 12 mm | 文字サイズ |
| `fontScale` | 数値 | `1` | 文字サイズの倍率。カスケードの後に `fontSize` に掛ける（[3.8.1](03-document-format.md#381-合成の規則)）。組み込みスタイル（`shout` など）が使う |
| `glyphScale` | `[横, 縦]` | `[1, 1]` | 字形の縦横の倍率。長体（横 < 1）・平体（縦 < 1）に使う。字送り・行送りは変えない（P1） |
| `weight` | 数値 | フォントの値 | 可変フォントの太さ（P1） |
| `color` | Paint | `black`（吹き出しでは塗りに応じて自動、[6.5](06-balloons.md#65-塗りfill)） | 文字の塗り。トーンやグラデーションも使える |
| `writing` | `vertical` \| `horizontal` | レンダリング時の言語（[3.10](03-document-format.md#310-meta)）が `ja` なら `vertical`、それ以外は `horizontal` | 縦書き（右から左へ列を進める）・横書き |
| `lineHeight` | 数値 \| Length | 縦書き 1.45、横書き 1.4 | 行送り。数値は文字サイズの倍数、長さは絶対値（`H` 単位も使える） |
| `letterSpacing` | Length（`em`） | `0`（`sfx` は `-0.03em`） | 字間（ベタ組みが 0） |
| `align` | `start` \| `center` \| `end` \| `justify` | 吹き出しの縦書きは `start`、吹き出しの横書きは `center`、その他は `start` | 行の揃え。縦書きの `start` は天揃え |
| `blockAlign` | `start` \| `center` \| `end` | `center` | 箱の中での文字のかたまりの位置（`text` で `size` を固定した場合） |
| `wrap` | `auto` \| `none` \| `char` \| `phrase` \| `balanced` | `auto` | 改行の方法（[7.6](#76-改行と禁則処理)） |
| `maxChars` | 数値 | 吹き出しの縦書き 8、吹き出しの横書き 14、その他はなし | 1 行の最大文字数（全角 1、半角 0.5 として数える）。吹き出しの本文に手で改行を入れた場合、既定値はその最長の行まで（既定の 1.5 倍を上限に）広げ、作者の改行を保つ |
| `maxExtent` | Length | - | 1 行の最大の長さ |
| `kinsoku` | `strict` \| `normal` \| `loose` \| `none` | `strict` | 禁則の強さ（[7.6.4](#764-禁則)） |
| `hanging` | 真偽値 | `false` | 句読点のぶら下げ |
| `punctCompress` | `none` \| `halfwidth` | `halfwidth` | 連続する約物の間を詰める |
| `tcy` | `auto` \| `none` \| TcyOptions | `auto` | 縦中横（[7.10](#710-縦中横)） |
| `latin` | `auto` \| `rotate` \| `upright` | `auto` | 縦書き中の欧文の向き（[7.4.4](#744-欧文と数字)） |
| `ruby` | RubyOptions | - | ルビの設定（[7.8](#78-ルビ)） |
| `emphasis` | EmphasisOptions | - | 傍点の設定（[7.9](#79-傍点)） |
| `lettering` | `typeset` \| `hand` \| LetteringOptions | 要素による（7.1） | 手書き風の揺らぎ（[7.15](#715-手書き風の文字)） |
| `markup` | 真偽値 | `true` | インラインマークアップを解釈するか |
| `normalize` | NormalizeOptions | 7.11 | 記号の正規化 |
| `features` | Map\<機能タグ, 真偽値 \| 数値\> | - | OpenType 機能（例: `{ palt: true }`） |
| `lang` | BCP 47 | `meta.lang` | この要素の言語（禁則と既定値の選択に使う） |

## 7.3 フォント

### 7.3.1 登録

```yaml
fonts:
  gothic: ./fonts/ZenKakuGothicNew-Bold.ttf
  antique: ./fonts/ZenAntique-Regular.ttf
  mincho:
    src: ./fonts/ShipporiMincho-Medium.ttf
  hiragino:
    src: ./fonts/HiraginoSans.ttc
    index: 6                          # コレクション内の番号
  dialogue:                           # ロール名のフォント（混植）
    compose:
      - { font: antique, ranges: [kana, punct] }
      - { font: gothic }
    fallback: [gothic]
  narration: mincho
  shout: ./fonts/DelaGothicOne-Regular.ttf
  sfx: shout
```

| キー | 型 | 説明 |
|---|---|---|
| `src` | パス | フォントファイル |
| `index` | 整数 | TTC / OTC の中の 0 始まりの番号（`src` は既定 0、`system` は省略すると名前だけで選ぶ） |
| `alias` | フォント名 | 別名。省略記法では拡張子のない文字列を書く |
| `compose` | ComposeItem[] | 混植（[7.3.4](#734-混植compose)） |
| `fallback` | フォント名[] | 字形がない場合に順に探すフォント |
| `variations` | Map\<軸, 数値\> | 可変フォントの軸の値（例: `{ wght: 700 }`、P1） |
| `bold` | フォント名 | `<b>` のときに使うフォント。なければ擬似太字（輪郭を 0.03 em 太らせる） |
| `system` | 文字列 | OS にインストールされたフォントの名前（[7.3.8](#738-システムフォント)） |
| `catalog` | カタログ ID | 同梱のカタログのフォント。必要なときに自動で取得する（[7.3.10](#7310-フォントのカタログと取得)）。省略記法は `catalog:<ID>[@<太さ>]` |
| `weight` | 数値 | `catalog` のフォントの太さ（例: `700`）。カタログにない太さはエラー |

### 7.3.2 形式

| 形式 | 優先度 |
|---|---|
| TTF（TrueType）、OTF（CFF / CFF2）、TTC / OTC | P0 |
| WOFF、WOFF2 | P1 |
| 可変フォント | P1 |
| カラーフォント（COLR、CBDT、sbix） | P2（P1 までは輪郭のみで描画し、情報 `FONT_COLOR_GLYPH_FLATTENED` を出す） |

### 7.3.3 ロール

要素の既定のフォントは、次のロール名で決める。ロール名と同じ名前で `fonts` に登録すると、そのフォントを使う。登録がない場合は、右の列の順に探す。

| ロール | 用途 | 未登録時に探す順 |
|---|---|---|
| `dialogue` | 通常のセリフ | `default` |
| `narration` | ナレーション、モノローグ、地の文字 | `dialogue` → `default` |
| `thought` | 心の声 | `dialogue` → `default` |
| `shout` | 叫び | `dialogue` → `default` |
| `whisper` | 小声 | `dialogue` → `default` |
| `sfx` | 描き文字 | 選択したフォントセットの `sfx` → `shout` → `dialogue` → `default` |
| `hand` | 手書き文字 | `dialogue` → `default` |
| `title` | 題 | `narration` → `dialogue` → `default` |
| `ruby` | ルビ | 親文字のフォント |
| `ui` | ノンブル、デバッグ表示 | 同梱の欧文フォント |

- 右の列の順に探しても `fonts` に見つからない場合は、フォントセット（`fontSet`、既定 `manga-basic`、[7.3.10](#7310-フォントのカタログと取得)）の**元のロール**のフォントを使う。たとえば `fonts` に `dialogue` だけを登録した場合、`thought` は登録した `dialogue` を使い、`narration` も登録した `dialogue` を使う（フォントセットより `fonts` の登録を優先する）。何も登録しない場合は、すべてのロールでフォントセットのフォントを使う。
- `fontSet: none` で、フォントセットも見つからない場合、日本語の文字を含む要素があればエラー（`FONT_NOT_CONFIGURED`）とする。
- 和文フォントはパッケージに同梱しない（1 書体で数 MB になるため）。代わりにフォントのカタログと取得の仕組みを同梱し、セットアップ時またはレンダリング時にダウンロードする（7.3.10）。ノンブルとデバッグ表示用の小さな欧文フォント（SIL Open Font License のもの）だけは 1 つ同梱し、オフラインでも使えるようにする。

### 7.3.4 混植（compose）

漫画の写植では、かなにアンチック体、漢字にゴシック体を使う「アンチゴチ」が広く使われる。`compose` は、文字の範囲ごとに使うフォントを指定する。

```yaml
fonts:
  dialogue:
    compose:
      - { font: antique, ranges: [kana, punct], scale: 1.0 }
      - { font: gothic, ranges: [kanji, fullwidth, latin, digits] }
      - { font: symbols, ranges: ["U+2600-27BF"] }
    fallback: [gothic]
```

| キー | 型 | 説明 |
|---|---|---|
| `font` | フォント名 | 使うフォント |
| `ranges` | 範囲名 \| `"U+XXXX-YYYY"` の配列 | 対象の文字。省略するとすべての文字（最後の項目に使う） |
| `scale` | 数値 | 字面の大きさの補正（既定 1）。字送りは変えず、字の枠の中心を基準に字面だけを拡大・縮小する |
| `baselineShift` | Length（`em`） | 位置の補正（縦書きでは右方向、横書きでは上方向が正） |

| 範囲名 | 内容 |
|---|---|
| `kana` | ひらがな（U+3041〜309F）、カタカナ（U+30A0〜30FF のうち ヶ を除く）、カタカナ拡張（U+31F0〜31FF）、半角カナ（U+FF66〜FF9F） |
| `kanji` | CJK 統合漢字（U+4E00〜9FFF、拡張 A 以降）、CJK 互換漢字（U+F900〜FAFF、U+2F800〜2FA1F）、々 〆 〇 ヶ |
| `punct` | 和文の約物: CJK の記号と句読点（U+3000〜303F）、全角の記号（U+FF01〜FF0F、FF1A〜FF20、FF3B〜FF40、FF5B〜FF65）、中点（・）、三点リーダー（… ‥）、ダッシュ（― —）、‼ ⁇ ⁈ ⁉ |
| `fullwidth` | 全角英数字（U+FF10〜FF19、FF21〜FF3A、FF41〜FF5A） |
| `latin` | 基本ラテン文字・ラテン 1 補助・ラテン拡張の文字と記号（数字を除く） |
| `digits` | 半角数字 |
| `symbols` | 一般の記号（U+2000〜2BFF）のうち `punct` に含まれないもの（♡ ♪ ★ ☆ → など） |
| `emoji` | Unicode の `Extended_Pictographic` 性質を持つ文字と、絵文字の異体字セレクタ（U+FE0F）・ZWJ の連続 |

- 範囲は重なってもよい。文字ごとに、`compose` の項目を先頭から調べ、範囲に含まれ、かつ字形を持つ最初のフォントを使う。どれも持たない場合は `fallback` を順に調べる。
- シェーピングは、同じフォントが連続する範囲（ラン）ごとに行う。

### 7.3.5 フォールバック

字形が見つからない場合は、次の順に探す。

1. 混植の `compose` の項目
2. そのフォントの `fallback`
3. 設定ファイルの `fontFallback`（全体のフォールバック、[12.5](12-cli.md#125-設定ファイル)）
4. フォントセットのフォールバック（`manga-basic` では `noto-sans-jp`。必要な場合だけ取得する）
5. 同梱の欧文フォント（ASCII のみ）

### 7.3.6 字形の確認

- 準備の段階（[2.2](02-architecture.md#22-処理パイプライン)）で、すべての文字について使用するフォントと字形の有無を確認する。
- 字形が見つからない文字があれば警告（`FONT_MISSING_GLYPH`）を出し、その文字は `.notdef`（豆腐）で描く。診断には、要素の ID、文字、Unicode の値、試したフォントを含める。
- `mangacli fonts check <file>` で、ドキュメント全体の字形の有無を一覧できる（P1）。

### 7.3.7 太字と斜体

- `<b>` の太字は、フォントの `bold` で指定したフォントを使う。指定がない場合は輪郭を太らせた擬似太字にする。
- 擬似太字の縁取りは太らせた筆画の外側を基準にし、指定した縁の幅を保つ。
- 和文フォントには斜体がないため、斜体（`<i>`）は扱わない。傾けた文字が必要な場合は、`sfx` の `distort.skew` を使う。

### 7.3.8 システムフォント

`system: "Hiragino Sans W6"` のように、インストール済みのフォントを指定できる。フォントの名前テーブルから PostScript 名、フルネーム、ファミリー名（日本語名を含む）をこの順に探す。大文字・小文字は区別しない。ファミリー名に複数候補がある場合は標準の書体を優先する。特定のウェイトを使うには PostScript 名で指定する。

```yaml
fonts:
  dialogue:
    system: "Noto Sans CJK JP"
  narration:
    system: NotoSansCJKjp-Regular
    index: 0
```

`index` は省略可能。指定すると、名前と番号が両方合うフェイスのみを使う。TrueType、OpenType（CFF/CID を含む）、TTC / OTC が対象。候補の名前・コレクション内の番号・ファイルの場所は `mangacli fonts list --system` で確認できる。

macOS では `~/Library/Fonts`、`/Library/Fonts`、`/System/Library/Fonts`、Windows ではユーザーの `%LOCALAPPDATA%\Microsoft\Windows\Fonts` とシステムの `%WINDIR%\Fonts` を探す。Linux では fontconfig（`fc-list`）に登録されたフォントを探す。使用時は情報 `FONT_SYSTEM_USED` を出し、名前や番号が見つからない場合はエラー `FONT_NOT_FOUND` を出す。仕上がりはマシンのインストール状況に依存する。商用フォントは、利用者がライセンスを確認してインストールすること。

### 7.3.9 ライセンス

- フォントのライセンスの遵守は利用者の責任とする。ドキュメント・CLI のヘルプで注意を促す。
- 本ライブラリは文字を輪郭（パス）として出力する。PDF・SVG にもフォントのデータそのものは埋め込まない。ただし、ラスタ画像やアウトライン化した文字の利用についてもフォントのライセンスに条件がある場合がある。
- カタログのフォントは、すべて SIL Open Font License 1.1 のものに限る（7.3.10）。

### 7.3.10 フォントのカタログと取得

（P0）

和文フォントをパッケージに同梱する代わりに、再配布できるライセンスの和文フォントの**カタログ**と、それを取得する仕組みを同梱する。フォントは、セットアップ時（`mangacli fonts install`、`mangacli init`）にまとめて取得するか、レンダリング時に必要になった時点で自動で取得する。

#### カタログ

カタログはパッケージに同梱する JSON ファイルで、フォントのファイルごとに次の項目を持つ。

| 項目 | 内容 |
|---|---|
| `id` | カタログ ID（例: `zen-kaku-gothic-new`） |
| `family`、`weight`、`style` | 書体名、太さ、スタイル |
| `url` | 取得元。版を固定した URL とする（例: 公開リポジトリの特定のコミットのファイル）。ブランチ名など、内容が変わりうる URL は使わない |
| `sha256`、`bytes` | ファイルのハッシュと大きさ |
| `license` | `OFL-1.1`。ライセンス文の URL とハッシュ、著作権表示 |
| `coverage` | 収録している文字の範囲（Unicode の範囲の列）。ダウンロードする前に、どの文字にどのフォントが要るかを判定するために使う |
| `revision` | カタログの項目の版 |

初期のカタログに収録する候補を次に示す。最終的な収録は、M1 でライセンスと取得元を確認して決める。

| カタログ ID | 書体 | 太さ | 主な用途 |
|---|---|---|---|
| `zen-antique` | Zen Antique | 400 | アンチック体（アンチゴチのかな） |
| `zen-kaku-gothic-new` | Zen Kaku Gothic New | 400、500、700、900 | ゴシック体（アンチゴチの漢字） |
| `shippori-mincho` | Shippori Mincho | 400、500、700 | 明朝体（ナレーション） |
| `dela-gothic-one` | Dela Gothic One | 400 | 極太ゴシック体（描き文字） |
| `rocknroll-one` | RocknRoll One | 400 | 太く力強い描き文字 |
| `mochiy-pop-one` | Mochiy Pop One | 400 | 軽めで丸みのある描き文字 |
| `zen-maru-gothic` | Zen Maru Gothic | 500、700、900 | 丸ゴシック体（題、やわらかいセリフ） |
| `rampart-one` | Rampart One | 400 | 立体的な描き文字 |
| `yomogi` | Yomogi | 400 | 手書き風 |
| `klee-one` | Klee One | 400、600 | 手書き風（硬筆） |
| `yusei-magic` | Yusei Magic | 400 | マジックペン風の手書き |
| `yuji-boku` | Yuji Boku | 400 | 毛筆体（墨の太い筆。題字、筆で書いた大きな字） |
| `yuji-syuku` | Yuji Syuku | 400 | 毛筆体（端正な楷書。筆で書いた名前、看板、書道の作品） |
| `noto-sans-jp` | Noto Sans JP | 400、600、700 | 字形の欠落を補うフォールバック |

#### 参照の書き方

```yaml
fonts:
  antique: catalog:zen-antique
  gothic: catalog:zen-kaku-gothic-new@700
  mincho: { catalog: shippori-mincho, weight: 500 }
  dialogue:
    compose:
      - { font: antique, ranges: [kana, punct] }
      - { font: gothic }
```

- ドキュメントに書けるのはカタログ ID だけであり、任意の URL のフォントは指定できない。
- カタログにない ID はエラー（`FONT_CATALOG_UNKNOWN`）。

#### フォントセット

トップレベルの `fontSet`（既定は、レンダリング時の言語が `ja`・`zh`・`ko` なら `manga-basic`、それ以外なら `comic-basic`）は、ロールとフォントの対応表である。`fonts` に登録のないロールに使う（7.3.3）。`fontSet: none` で無効にする。

| ロール | `manga-basic` のフォント |
|---|---|
| `dialogue` | 混植（アンチゴチ）: かな・約物は `zen-antique`（字面 1.04 倍）。その他は、インストール済みなら中ゴシックBBB（`GothicBBBPr6N-Medium` など）、無ければ `noto-sans-jp@600`、それも使えなければ `zen-kaku-gothic-new@500`。漢字をかなと同じか、わずかに黒い太さにそろえる。フォールバックは `noto-sans-jp@400` |
| `thought`、`whisper` | `dialogue` と同じ |
| `narration` | `shippori-mincho@500` |
| `shout` | ゴシックMB101 U（インストール済み）→ 新ゴ U（インストール済み）→ `zen-kaku-gothic-new@900`（`as: shout`、`as: scream`） |
| `sfx` | `yuji-syuku@400`（筆の強弱がある描き文字。強い衝撃音には `catalog:rocknroll-one` も指定可） |
| `hand` | `yomogi` |
| `title` | システムのゴシックMB101 U・新ゴ U、なければ `noto-sans-jp@900`（扉の題字向けの、画の端が四角い極太ゴシック。ない字は `zen-kaku-gothic-new@900`） |

| ロール | `comic-basic` のフォント（欧米のコミックの写植） |
|---|---|
| `dialogue`、`thought`、`whisper` | `comic-neue@700` |
| `narration`、`hand` | `comic-neue@400` |
| `shout` | `bangers`（字幅の狭い書体のため 1.35 倍） |
| `sfx`、`title` | `bangers` |

いずれもフォールバックは `noto-sans-jp`。

叫び用の市販フォントは、ファミリー名、フルネーム、PostScript 名でインストール済みのものだけを探す。同梱・自動取得はしない。

CJK 以外の言語の横書きの吹き出しは、コミックの慣習に合わせて既定で大文字にする（`textTransform: auto`。`uppercase` で常に、`none` で変換しない）。また、CJK 以外の言語では `'` `"` を `’` `“` `”` に置き換え、`...` やダッシュは変換しない。

フォントセットのフォントは、ドキュメントで実際に使うロールと文字に必要なものだけを取得する。たとえばフォールバックの `noto-sans-jp` は、主のフォントの `coverage` にない文字がある場合だけ取得する。

#### 取得の流れ

1. 準備の段階（[2.2](02-architecture.md#22-処理パイプライン) の Prepare、メインスレッド）で、必要なカタログのフォントを列挙する。
2. 次の順に探す。
   1. プロジェクトのフォントの置き場所（`fontDir`。既定はなし）
   2. ユーザーのキャッシュ（`fontCacheDir`。既定は macOS では `~/Library/Caches/mangacli/fonts`、Linux では `$XDG_CACHE_HOME/mangacli/fonts`（既定 `~/.cache/mangacli/fonts`）、Windows では `%LOCALAPPDATA%\mangacli\Cache\fonts`）
3. 見つからず、`fontDownload` が `auto`（既定）の場合はダウンロードする。
   - HTTPS でのみ取得する。リダイレクトは、カタログに書かれた取得元のホストの範囲でのみ許す。
   - SHA-256 を検証してから、一時ファイルから名前を変えてキャッシュに置く。ライセンス文も同じ場所に保存する。
   - 複数のプロセスが同時に取得しないよう、フォントごとにロックファイルで排他する。
   - 取得中は情報（`FONT_DOWNLOADING`）と進捗（`onProgress`、段階 `prepare`）を出す。
4. 取得に失敗した場合はエラー（`FONT_DOWNLOAD_FAILED`）、ハッシュが一致しない場合はファイルを捨ててエラー（`FONT_INTEGRITY_FAILED`）とする。`fontDownload: never` で手元にない場合はエラー（`FONT_DOWNLOAD_DISABLED`）とし、ヒントに `mangacli fonts install --for <ファイル>` を示す。

#### セットアップ時の取得

- `mangacli fonts install`（[12.3.8](12-cli.md#1238-fonts)）で、フォントセット・ドキュメントが使うフォント・指定した ID のフォントを取得する。`--dir ./fonts` を指定すると、ユーザーのキャッシュではなくプロジェクトの中に置く（オフラインでの作業、リポジトリへの同梱、CI 向け）。
- `mangacli init` は、既定で `manga-basic` のフォントを取得する（`--no-fonts` で省略）。
- npm の `postinstall` は使わない。`--ignore-scripts` を使う環境や CI、パッケージのインストール時のネットワークアクセスを避けるためである。利用者は、自分の `package.json` の scripts に `mangacli fonts install --for manga.yaml` を書いてよい。
- サーバーや CI では、ビルド時（コンテナイメージの作成時など）に `fonts install` を実行し、実行時は `fontDownload: never` にすることを推奨する。

#### 安全性と再現性

- フォントの取得は、素材の URL の取得（既定で無効、[2.13](02-architecture.md#213-セキュリティ)）とは別の許可として扱う。取得先はカタログに書かれた URL に限られ、内容はハッシュで検証するため、`fontDownload: auto` を既定とする。
- `fontMirror`（環境変数 `MANGACLI_FONT_MIRROR`）で、取得元の URL の接頭辞を社内のミラーなどに置き換えられる。ハッシュで検証するため、ミラーでも同じファイルであることが保証される。
- カタログのフォントを別のファイルに差し替える（書体の版を上げる）場合は、`engine` の番号を上げる（[3.19.1](03-document-format.md#3191-エンジンのバージョンengine)）。カタログは旧い項目も保持し、旧い `engine` のドキュメントでは旧いファイルを使う。

#### ライセンス

- カタログのフォントは SIL Open Font License 1.1 のものに限る。
- フォントで描いた出力（画像・PDF）には、OFL によるライセンス表示の義務はない。フォントのファイルそのものを再配布する場合（`--dir` で取得したファイルをリポジトリに含めるなど）は、ライセンス文を同梱する。
- `mangacli fonts licenses` で、使用したフォントのライセンス文と著作権表示を一覧・書き出しできる。


## 7.4 縦書き

### 7.4.1 列の構成

- 列は右から左へ進む。列の間隔（行送り）は `fontSize × lineHeight`。
- 列の中の文字は上から下へ進む。文字の送りは、フォントの縦書きの送り幅（`vmtx`、なければ 1 em）に `letterSpacing` を加えた値。
- 文字の全角の枠（em box）を列の中心に置く。枠の中での字形の位置は、フォントの縦書きのメトリクス（`vmtx`・`VORG`・`vhea`。HarfBuzz が返す位置）に従う。句読点・小書きの仮名・括弧などは、字形そのものが枠の中で偏った位置に作られているため、字面の中心を列の中心に合わせてはならない。
- フォントが縦書きのメトリクスを持たない場合は、横書きの送り幅の中央を列の中心に合わせ、縦方向は ascent と descent の中央を枠の中央に合わせる。
- シェーピングは HarfBuzz で方向を上から下（TTB）として行う。HarfBuzz は `vert` 機能を自動で適用する。`vrt2`（欧文を回転済みの字形にする機能）は、欧文の向きの設定（7.4.4）と衝突するため使わない。

### 7.4.2 縦組み用字形がない場合

文字の縦書きでの向きは、Unicode の縦書きの向きの性質（UAX #50 の `Vertical_Orientation`）に従う。

| 値 | 意味 | 処理 |
|---|---|---|
| `U` | 正立 | そのまま置く |
| `R` | 回転 | 時計回りに 90 度回転して置く |
| `Tu` | 縦組み用字形が必要（なければ正立） | `vert` の字形を使う。字形がなければ正立のまま、下表の位置の補正を行う |
| `Tr` | 縦組み用字形が必要（なければ回転） | `vert` の字形を使う。字形がなければ時計回りに 90 度回転する（括弧類、長音記号、ダッシュ、波ダッシュ、三点リーダーなど） |

`Tu` の文字で縦組み用字形がない場合の位置の補正:

| 文字 | 補正 |
|---|---|
| 句読点（、。，．） | 字形を全角の枠の左下 1/4 から右上 1/4 へ平行移動する（右へ 0.5 em、上へ 0.5 em） |
| 小書きの仮名（ぁぃぅぇぉっゃゅょゎゕゖァィゥェォッャュョヮヵヶ） | 右へ 0.1 em、上へ 0.1 em 移動 |

縦組み用字形を持たないフォントを縦書きで使った場合は、情報（`FONT_NO_VERTICAL_FORMS`）を出す。

### 7.4.3 約物の扱い

- 連続する約物（例: `」「`、`。」`）の間は、`punctCompress: halfwidth` のとき二分（0.5 em）詰める。
- 列頭の始め括弧は詰めない。
- `――`（ダッシュ 2 つ）は、字形の間に隙間ができないように連続した線として描く。ダッシュの字形が字送りの枠からはみ出すフォントでは、線を枠の長さに合わせて伸縮し、前後の文字に重ならないようにする。
- 縦組みの `…` は、直径約 0.13em の小さな点 3 つを 1 字分の中央に揃える。`……` は 2 字分で 6 点を描く。横組みの `…` と二点リーダー `‥` はフォントの字形を使う。
- 縦書きで縦用の字形（`vert`）を持たないフォントの `〜`・`ー`・`―`・括弧類などは、90 度回転して縦向きにする。

### 7.4.4 欧文と数字

`latin` の値によって、縦書き中の半角英数字の向きを決める。

| 値 | 処理 |
|---|---|
| `auto`（既定） | 縦中横の条件（[7.10](#710-縦中横)）に合う連続は縦中横にする。縦中横にならない数字の連続（`2024`）と、前後が欧文でない大文字の単語のうち、2 文字（`OK`、`TV`）は縦中横に、3 文字（`DVD`）は 1 文字ずつ正立させる。それ以外の欧文の単語は時計回りに 90 度回転（横倒し）する |
| `rotate` | すべて横倒しにする |
| `upright` | 1 文字ずつ正立させる |

全角英数字は常に正立させる。

### 7.4.5 揃え

| `align` | 縦書き | 横書き |
|---|---|---|
| `start` | 天揃え（各列の上端を揃える） | 左揃え |
| `center` | 各列を縦方向の中央に揃える | 中央揃え |
| `end` | 地揃え（各列の下端を揃える） | 右揃え |
| `justify` | 各列を、最も長い列の長さに均等割り付け（最終列を除く） | 両端揃え（最終行を除く） |

## 7.5 横書き

- 行は上から下へ進む。行送りは `fontSize × lineHeight`。
- シェーピングは HarfBuzz で方向を左から右（LTR）として行う。右から左へ書く文字（アラビア文字など）の双方向処理は P2 とする。
- 欧文は単語の区切り（空白）で改行する。単語の途中での改行（ハイフネーション）は P2 とする。

## 7.6 改行と禁則処理

### 7.6.1 改行の方法（wrap）

| 値 | 処理 | 優先度 |
|---|---|---|
| `none` | 明示的な改行（YAML の改行、`<br>`）だけで改行する | P0 |
| `char` | 明示的な改行に加え、行の長さの上限を超えるときに文字単位で改行する | P0 |
| `phrase` | 明示的な改行に加え、行の長さの上限を超えるときに文節に近い単位で改行する | P1 |
| `balanced` | `phrase` と同じ単位で、行の長さがそろうように改行位置を選ぶ | P1 |
| `auto` | `phrase` が使える場合は `phrase`、使えない場合は `char` | P0 |

- 漫画のセリフは、作者が意味の切れ目で手動改行するのが基本である。手動の改行は常に尊重し、それでも上限を超える行だけを自動で改行する。
- 吹き出し（`as: narration` の箱を含む）の全角スペース（U+3000）は、縦書き・横書きともに意味の切れ目として改行する（縦書きでは次の列へ送る）。スペース自体は表示しない。連続する全角スペースは 1 回の改行にまとめ、明示的な改行に隣接する場合は空行を増やさず、本文の先頭・末尾の全角スペースは取り除く。半角スペース、通常のテキスト・描き文字、`as: aside` は変更しない。
- 行の長さの上限は、`maxChars`、`maxExtent`、固定サイズの箱の大きさのうち、最も小さいものとする。

### 7.6.2 文節に近い単位（phrase）

全角スペースによる吹き出しの改行は、マークアップを解釈した後の本文に適用する。ルビの親文字・読みやタグの属性内の全角スペースは保持する。`markup: false` やエスケープした `<br>` は文字として表示し、改行として扱わない。

1. `Intl.Segmenter`（`granularity: "word"`）で単語に分ける。
2. 次の単語を直前の単語に連結し、文節に近い単位にする。
   - ひらがなだけからなる単語で、直前の単語が漢字またはカタカナで終わるもの（送り仮名・助詞・助動詞）
   - 約物、長音記号、小書きの仮名で始まるもの
   - 数字に続く 1〜2 文字の漢字（`2024年`、`3人`）と、`第` に続く数字
   - ただし、句読点・感嘆符などの直後の単語と、独立して使うひらがなの語（`また`、`なんか`、`ちょっと` などの副詞・指示語、`おごる` のようなひらがな書きの動詞の終止形）は連結しない
3. カタカナの連続、数字の連続、欧文の単語、縦中横、ルビの親文字の中では改行しない。
4. 1 つの単位が行の長さの上限を超える場合は、その単位の中の単語（`Intl.Segmenter` の 2 文字以上の単語）の先頭で改行する。それもできなければ `char` と同じ規則で改行する。

> `Intl.Segmenter` の結果は Node.js に同梱される ICU のバージョンに依存する。改行位置を固定したい場合は、手動の改行か `<wbr>`・`<nobr>` を使う。API では区切りの関数を差し替えられる（[11.5](11-api.md#115-レンダリングオプション)）。

### 7.6.3 balanced

`phrase` の単位を使い、行数を最小にしたうえで、行の長さの分散が最小になる改行位置を動的計画法で選ぶ。吹き出しの形が楕円で `align: center` の場合は、中央の行が長くなる配分（楕円の弦の長さに比例する目標値）との差を最小にする。

### 7.6.4 禁則

禁則の強さは、CSS Text Module Level 3 の `line-break`（`strict`・`normal`・`loose`）の日本語の規則に合わせる。漫画の写植の慣習に合わせ、既定は `strict` とする。

| 文字の分類 | 文字 | `strict` | `normal` | `loose` |
|---|---|---|---|---|
| 終わりの約物 | `、。，．）］｝」』】〕〉》〙〗’”｠»` と半角の `),.]}>` | 行頭禁止 | 行頭禁止 | 行頭禁止 |
| 感嘆符・疑問符 | `？！‼⁇⁈⁉` と半角の `?!` | 行頭禁止 | 行頭禁止 | 行頭禁止 |
| 中点・コロン類 | `・：；` と半角の `:;` | 行頭禁止 | 行頭禁止 | 許可 |
| 繰り返し記号 | `々〻ゝゞヽヾ` | 行頭禁止 | 行頭禁止 | 許可 |
| ハイフン類・波ダッシュ | `‐–〜～゠` | 行頭禁止 | 行頭禁止 | 許可 |
| 小書きの仮名・長音記号 | `ぁぃぅぇぉっゃゅょゎゕゖァィゥェォッャュョヮヵヶ`、カタカナ拡張の小書き（U+31F0〜31FF）、`ー` | 行頭禁止 | 許可 | 許可 |
| 始めの約物 | `（［｛「『【〔〈《〘〖‘“｟«` と半角の `([{<` | 行末禁止 | 行末禁止 | 行末禁止 |
| 分離禁止 | `……`、`――`、`‥‥`、縦中横の単位、ルビの親文字のまとまり、数字の連続（`1,000` などの区切りを含む）、欧文の単語 | 間で改行しない | 同左 | 同左 |

`none` は禁則を行わない（分離禁止のみ守る）。

処理は**追い出し**（改行位置を前に移し、禁則の文字を次の行へ送る）を基本とする。追い出しによって行が 1 文字になる場合は**追い込み**（禁則の文字を前の行に含め、上限を 1 文字超えることを許す）とする。`hanging: true` の場合、行頭禁則の句読点（`、。，．`）は前の行の外へぶら下げる。

## 7.7 インラインマークアップ

本文の中で、ルビ・傍点・縦中横・部分的な書式を指定する。日本語の Web 小説で広く使われる記法（ルビ・傍点）と、タグ形式の記法を組み合わせる。

| 記法 | 意味 | 例 |
|---|---|---|
| 改行 | 行（縦書きでは列）の区切り | YAML のブロックスカラーの改行、`<br>` |
| `｜親文字《ルビ》` | ルビ（`｜` は全角または半角の縦線） | `｜放課後《アフタースクール》` |
| `漢字《ルビ》` | ルビ。直前の漢字の連続を親文字とする | `東京《とうきょう》` |
| `《《文字》》` | 傍点 | `《《本当に》》` |
| `<ruby=るび>親文字</ruby>` | ルビ（タグ形式） | `<ruby=とうきょう>東京</ruby>` |
| `<em>文字</em>` | 傍点（タグ形式）。`<em mark=dot>` で種類を指定 | |
| `<tcy>文字</tcy>` | 縦中横 | `<tcy>24</tcy>時` |
| `<upright>文字</upright>` | 縦書きで正立させる | `<upright>NG</upright>` |
| `<sideways>文字</sideways>` | 縦書きで横倒しにする | |
| `<b>文字</b>` | 太字 | |
| `<size=倍率または長さ>文字</size>` | 文字サイズ | `<size=1.4>ドカン</size>`、`<size=18Q>` |
| `<big>`、`<small>` | 1.25 倍、0.8 倍 | |
| `<scale x=倍率 y=倍率>文字</scale>` | 長体・平体（`glyphScale`、P1） | `<scale x=0.8>` |
| `<font=名前>文字</font>` | フォント | `<font=hand>` |
| `<color=色>文字</color>` | 色 | `<color=#c00>` |
| `<shake>文字</shake>` | 震える文字（1 文字ずつ不規則にずらす、P1） | |
| `<hand>文字</hand>` | 手書き風の揺らぎ（P1） | |
| `<space=長さ>` | 空白を入れる | `<space=1em>` |
| `<wbr>` | ここで改行してよい | |
| `<nobr>文字</nobr>` | 間で改行しない | |

- タグの属性は `<名前=値>` または `<名前 属性=値>` の形で書く。値に空白を含む場合は引用符で囲む。
- タグは正しく入れ子にしなければならない。閉じていないタグ、対応しない閉じタグはエラー（`TEXT_MARKUP_UNBALANCED`）。未知のタグはエラー（`TEXT_UNKNOWN_TAG`）。
- 記号そのものを書く場合は、`\《`、`\》`、`\｜`、`\|`、`\<`、`\\` とエスケープする。
- `漢字《ルビ》` の直前に漢字がない場合は、`《ルビ》` を通常の文字として扱い、情報（`TEXT_RUBY_NO_BASE`）を出す。
- `markup: false` のときは、すべてを通常の文字として扱う。

## 7.8 ルビ

```yaml
ruby:
  size: 0.5
  position: auto
  align: center
  overhang: 1
```

| キー | 型 | 既定値 | 説明 |
|---|---|---|---|
| `size` | 数値 | `0.5` | 親文字の文字サイズに対する比 |
| `font` | フォント名 | `ruby` ロール | ルビのフォント |
| `position` | `auto` \| `right` \| `left` \| `over` \| `under` | `auto` | 縦書きでは右、横書きでは上 |
| `align` | `center` \| `start` | `center` | 中付き・肩付き |
| `overhang` | 数値 | `1` | ルビが親文字より長い場合に、前後の仮名に掛けてよいルビの文字数 |
| `reserve` | `auto` \| `none` | `auto` | ルビが列（行）の間に収まらない場合に、その列の行送りを広げるか |

- ルビを半角の空白で区切ると（`東京《とう きょう》`）、親文字 1 文字ずつに割り当てる（モノルビ）。区切りの数と親文字の数が合わない場合はエラー（`TEXT_RUBY_MISMATCH`）。
- 親文字とルビの両方を全角の `／` で区切ると（`｜白石／陽和《しらいし／ひより》` または `<ruby=しらいし／ひより>白石／陽和</ruby>`）、区切りを表示せず、各語のルビを対応する親文字に詰めて配置する。区切った組の数が合わない場合や空の組がある場合はエラー（`TEXT_RUBY_MISMATCH`）。
- 区切らない場合はグループルビとし、親文字全体の中央に置く。
- ルビが親文字より長く、`overhang` を使っても収まらない場合は、親文字の字間を均等に広げる。`／` で区切った組は、隣のルビと重ならないよう、はみ出さずに配置する。
- 改行は、親文字とルビのまとまりの途中では行わない。

## 7.9 傍点

（P1）

| キー | 型 | 既定値 | 説明 |
|---|---|---|---|
| `mark` | `sesame` \| `open-sesame` \| `dot` \| `circle` \| `filled-circle` \| `triangle` | `sesame`（﹅） | 点の種類 |

## 7.10 縦中横

| キー | 型 | 既定値 | 説明 |
|---|---|---|---|
| `digits` | 整数 | `2` | 自動で縦中横にする半角数字の連続の最大桁数（0 で無効） |
| `marks` | 真偽値 | `true` | `!?`、`!!`、`?!`、`??`、`!!!` を自動で縦中横にする（全角・半角を問わない） |
| `latin` | 整数 | `0` | 自動で縦中横にする半角英字の連続の最大文字数 |

- `tcy: auto` は上表の既定値、`tcy: none` は自動の縦中横を無効にする。`<tcy>` による手動の指定は常に有効。
- 縦中横の文字は、横に並べて 1 em の枠に収める。幅が 1 em を超える場合は横方向に縮める（最小 0.5 倍）。それでも収まらない場合は警告（`TEXT_TCY_TOO_LONG`）を出し、0.5 倍で描く。
- 縦中横にした `!?` などは、前後の文字と同じ大きさに見えるよう、縦方向の大きさを保つ。

## 7.11 記号の正規化

漫画の写植で一般的な表記に、入力を自動で整える。`normalize` で個別に無効にできる。

| キー | 既定値 | 処理 |
|---|---|---|
| `ellipsis` | `true` | `...`、`・・・`、`。。。` を `…` に置き換える |
| `ellipsisPair` | `false` | 単独の `…` を `……` にする |
| `dash` | `true` | `--`、単独の `―` を `――` に置き換える。罫線の `─`・`━` も `―` として扱う（縦書きで縦向きになり、続けて 1 本の線になる） |
| `fullwidthMarks` | 縦書きでは `true` | 半角の `!`、`?` を全角にする（縦中横の対象は除く） |
| `waveDash` | `true` | `~` を `〜` に置き換える |
| `spaceAfterMarks` | `true` | 文の途中の `！`、`？` の後に、閉じ括弧・改行・約物が続かない場合は全角の空白を入れる |
| `dropTrailingPeriod` | `false` | 行末・本文の末尾の `。` を取り除く（漫画のセリフで句点を省く慣習） |
| `spaces` | `true` | 縦書きの半角空白を 0.25 em、全角空白を 1 em の空きにする |

正規化はマークアップの解析の後、組版の前に行う。正規化の結果は `mangacli inspect --text` で確認できる。

## 7.13 地の文字（text）

人物の顔のそばに置く「ボソッ」「ツッコミ」には `- { aside: ボソッ, who: taro }`、または dialogue の `as: aside` を使う（[6 章](06-balloons.md)）。枠のない吹き出しとして扱い、手書きフォント・文字の揺らぎ・白フチ・小さな傾きを付け、顔と他の吹き出しを避ける。`text` 自体にはこの自動配置やしっぽは付かない。

吹き出しを持たない文字である。ナレーション、モノローグ、注釈（※〜）、手書きの書き込み、題、作者の欄外の言葉などに使う。

```yaml
- text: その日、僕は初めて嘘をついた
  place: top-right
  font: narration
  outline: 0.8mm white

- type: text
  text: ※ここ大事
  font: hand
  lettering: hand
  fontSize: 9Q
  writing: horizontal
  at: [20%, 85%]
  rotate: -6deg
```

| キー | 型 | 既定値 | 説明 |
|---|---|---|---|
| `text` | 文字列 | 必須 | 本文 |
| `who` | キャラクター ID | - | 発話者（吹き出しのないセリフの場合）。セリフ一覧に使う |
| `size` | Size \| `auto` | `auto` | 箱の大きさ。固定した場合は箱の中で改行する |
| `background` | Paint | `none` | 文字の背後に敷く板の塗り |
| `padding` | Length \| `[縦, 横]` | `[0.45em, 0.6em]` | 板の余白（`background` の板が線や絵に触れないよう、文字の周りに地を空ける） |
| `stroke` | Stroke | `none` | 板の輪郭線 |
| `overflow` | `shrink` \| `clip` \| `error` | `shrink` | 固定サイズの箱に収まらない場合の処理（[6.7.4](06-balloons.md#674-収まらない場合) と同じ） |
| `outline` | Outline[] | `[{ width: 0.8bmm, color: paper }]` | 縁取り。絵や効果線の上でも読めるよう、既定で白フチを付ける（小さい文字では字間までつながって地の白になる）。`none` で付けない |
| 組版・装飾のプロパティ | - | - | 7.2、7.12 |
| 共通プロパティ | - | - | [5.2](05-elements-and-images.md#52-共通プロパティ) |

## 7.14 描き文字（sfx）

描き文字も安全領域外では `TEXT_OUTSIDE_SAFE_AREA`、見開きののど付近では `TEXT_NEAR_FOLD` を警告する。意図的なはみ出しを妨げず、警告があっても描画する。
断ち切りなどで意図的にはみ出す描き文字には `bleed: true` を指定すると、その要素の `TEXT_OUTSIDE_SAFE_AREA` だけを抑制できる。`TEXT_NEAR_FOLD` や描画・クリップには影響しない。

これらの警告は吹き出し・地の文字にも共通で、安全領域外では各辺の断裁線または安全線からの超過量と安全線までの移動量、のど付近ではのどとの位置関係と警告帯を避ける左右それぞれの移動量を示す。距離は文書の単位にかかわらず mm（原則小数第1位）で表示する。移動量は不足しないよう 0.1 mm 単位で切り上げる。ただし反対側が安全線の許容差 0.5 mm を越える場合は、両側が許容範囲に収まる細かい移動量を示す。移動だけでは収まらない場合は必要な縮小量を示す。px 文書は対象外。

（P1）

擬音・擬態語を、絵の一部として大きく装飾的に描く。フォントの字形を出発点として、文字ごとの変形、全体の歪み、輪郭の揺らぎ、縁取りを加える。

```yaml
- sfx: ドドドド
  at: [80%, 50%]
  fontSize: 14mm
  writing: vertical
  grow: 0.15
  perChar:
    rotate: [-12deg, 12deg]
    jitter: 1.5mm
  distort: { roughen: 0.4, warp: 0.3 }
  color: black
  outline: [{ width: 1mm, color: white }]

- type: sfx
  text: キラーン
  font: hand
  color: white
  outline: [{ width: 0.35mm, color: black }]
  path: { kind: arc, angle: 40deg }
```

| キー | 型 | 既定値 | 説明 |
|---|---|---|---|
| `text` | 文字列 | 必須 | 文字（マークアップは `<size>`、`<color>`、`<font>`、`<space>` のみ有効） |
| `fontSize` | Length | 12 mm | 基準の文字サイズ |
| `bleed` | 真偽値 | `false` | 意図的なはみ出しの安全領域警告だけを抑制する |
| `writing` | `vertical` \| `horizontal` | 本文と同じ（言語が `ja` なら `vertical`、それ以外は `horizontal`） | 並べる向き |
| `letterSpacing` | Length（`em`） | `-0.03em` | 基礎の字送り。`perChar.overlap > 0` ではインク外接矩形の重なりを優先する。`overlap: 0em` と負の字間では、経路なしの文字間に最低 0.03em、小書き仮名の前は 0.04em 空ける |
| `path` | SfxPath | - | 文字を並べる経路（下表） |
| `grow` | 数値 | 自動 | `impact` は先頭 130% → 末尾 80%（`shrink`）、`speed` は先頭 95% → 末尾 130%（1 文字なら 130%）。指定時は `perChar.scale` のプリセット・始点終点より優先し、1 + `grow` × (n − 1)。`0` で等サイズ・面積補正なし。従来のランダム倍率は乗算する |
| `smallKanaScale` | 数値（0.1〜1） | `0.6` | 促音・拗音は対応する通常サイズの仮名の骨格を一度だけ縮小し、隣の文字に近い絶対筆画幅になるよう太さを補正する。`1` で縮小を無効 |
| `rotate` | Angle | `-6deg` | 単語全体の動く向き。個々の文字の傾きではなく、全体を一緒に回転する |
| `perChar` | `{ rotate, scale, overlap, jitter }` | `{ overlap: 0.22em }` | シードから再現可能な変形。`scale`・`overlap` は下表。`rotate`（Angle の Range）と `jitter`（両軸のずれ、Length）は指定したときだけ適用する |
| `chars` | CharOverride[] | - | 文字の番号ごとの上書き（`{ index, rotate, scale, offset, color }`） |
| `brush` | `false` \| `{ style, taper, entry, wobble }` | `{ style: impact, taper: 1, entry: 1, wobble: 0.01 }` | `impact` は太い胴体と短い抜き、押し込んだ入り。`speed` は長めの抜きと軽い入り（`entry: 0.35, wobble: 0.04`）。`taper`（0〜2）、`entry`（0〜2）、`wobble`（0〜0.2）を上書き可能。`false` で筆圧加工なし（太さ補正は維持） |
| `distort` | Distort | `{ roughen: 0.4, warp: 0, skew: 0deg }` | 全体の歪み（下表）。輪郭の揺れの係数は `roughen × fontSize × 0.02`。既定の 12bmm では 0.096bmm（約 0.1bmm）にシード付きノイズを掛け、x・y に同じ変位を加える |
| `color` | Paint | `black` | 文字の塗り |
| `outline` | Outline[] | 白、基準サイズの 12% ＋ その外側に黒 0.25bmm | 語全体で同じ幅の二重フチ。幅は累積ではなく字形からの絶対距離。各層は和集合した一つのパスで、隣接するフチの境目に線を引かない。空白や細いフチで届かない箇所は無理につながない。`none` で無効、明示した配列で両方を上書き可能 |
| `edge` | Stroke | `none` | 字形の輪郭を手描きの線でなぞる（例: 白抜き文字の黒い輪郭） |
| `hollow` | 真偽値 | `false` | 中を抜き、`edge` の線だけを描く |
| `lettering` | Lettering | `hand` | 手書き風の揺らぎ（7.15） |
| `motion` | `{ trail, direction }` | - | 残像（P2） |

長音・波線 `ー`・`〜`・`～`（半角 `ｰ` と縦書き用の `︱`・`︲`・`︴` も）は、進行方向だけを 1.6 倍に伸ばす。横幅（縦書き）・高さ（横書き）は変えず、既存の回転・経路変形を適用する。倍率は固定。

| `perChar` のキー | 値 | 動作 |
|---|---|---|
| `scale` | `shrink` | 1.3 → 0.8（`impact` の既定） |
| `scale` | `grow` | 0.85 → 1.3 |
| `scale` | `burst` | 0.9 → 中央 1.35 → 0.9（1 文字は 1.35） |
| `scale` | `flat` | 1 倍 |
| `scale` | `{ from: n, to: n }` | 正の始点・終点を線形補間。1 文字なら `impact` は始点、`speed` は終点 |
| `scale` | 数値、`[min, max]`、`{ min, max, dist? }` | 従来どおり、既定の推移に掛けるシード付き倍率（配列は始点・終点ではない） |
| `overlap` | Length（既定 `0.22em`） | フチを含まない字形の外接矩形を基準に、小さい方の変形後の文字サイズに比例して詰める。塗りまでつながって読みにくくならないよう、実際の字形の輪郭と太らせる幅から間隔を補正する。`0em`（負値も 0 扱い）で通常の字間に戻す。明示した空白・文字ごとの offset は補正後に加える |

サイズ推移は通常サイズの文字を基準に補間し、小書き仮名には `smallKanaScale` を乗算する。重なりが有効なときは、推移と間隔を保つための自動の面積拡大は行わない。詰めた文字位置を `line`・`arc`・`wave`・`points` 上へ写し、各文字を経路の接線に合わせる。`points` は詰めた字送りの距離で折れ線をたどる（文字列を点列の全長へ引き伸ばさない）。

見本: [gallery-sfx.yaml](examples/gallery-sfx.yaml)。

| `path.kind` | パラメータ | 説明 |
|---|---|---|
| `line` | `angle` | 直線（既定）。`angle` で傾ける |
| `arc` | `angle`（弧の中心角）、`radius` | 円弧に沿って並べる |
| `wave` | `amplitude`、`wavelength` | 波に沿って並べる |
| `points` | `points`（Point[]） | 点を滑らかに通る曲線に沿って並べる |

| `distort` のキー | 範囲 | 説明 |
|---|---|---|
| `roughen` | 0〜1 | 字形の輪郭の細かな揺らぎ。手で描いた輪郭のガタつき |
| `warp` | 0〜1 | 低周波のノイズ場による全体のゆがみ |
| `skew` | Angle | 傾け（斜体の代わり） |
| `perspective` | `[上端の倍率, 下端の倍率]` | 台形状の遠近感 |
| `bulge` | -1〜1 | 中央の膨らみ（正）・すぼまり（負） |

描画の手順:

1. サイズ推移と文字ごとの上書きを適用し、字形を詰めて `path` の流れに沿って配置する。
2. 全字形の和集合を取り、全体を太らせて `brush` と `distort` を適用する。内側の抜けは、太らせた輪郭で自然に閉じる場合を除き残す。
3. 変形後の輪郭を広げ、`outline` を外側から層ごとに描く。
4. 塗り（`color`）を描き、`edge` があれば全体の輪郭を手描きの線でなぞる。`chars[].color` と色マークアップは塗りだけを分け、重なる部分では先頭側の色を優先する。

## 7.15 手書き風の文字

（P1）

```yaml
lettering:
  mode: hand
  rotate: 1.5deg
  offset: 0.03em
  scale: 0.04
  baseline: { amplitude: 0.04em, wavelength: 4em }
  wobble: 0.012em
  spacing: 0.03em
```

| キー | 型 | `hand` の既定値 | 説明 |
|---|---|---|---|
| `mode` | `typeset` \| `hand` | - | `typeset` は揺らぎなし |
| `rotate` | Angle | `1.5deg` | 文字ごとの回転の標準偏差 |
| `offset` | Length（`em`） | `0.03em` | 文字ごとの位置のずれの標準偏差 |
| `scale` | 数値 | `0.04` | 文字ごとの大きさのばらつきの標準偏差 |
| `baseline` | `{ amplitude, wavelength }` | `{ amplitude: 0.04em, wavelength: 4em }` | 行全体のうねり |
| `wobble` | Length（`em`） | `0.012em` | 字形の輪郭の揺らぎの振幅 |
| `spacing` | Length（`em`） | `0.03em` | 字送りのばらつきの標準偏差 |

- 揺らぎは要素のシードと文字の番号から決め、決定的である。
- 同じ文字が続いても同じ形にならない（文字ごとに異なる乱数を使う）。
- 手書き風の文字は、手書き風のフォント（`hand` ロール）と組み合わせると効果が高い。

## 7.16 多言語

（P1）

```yaml
locales:
  en:
    defaults:
      balloon: { writing: horizontal, font: dialogue-en, maxChars: 18 }
    fonts:
      dialogue-en: ./fonts/ComicNeue-Bold.ttf

pages:
  - panels:
      - layers:
          - type: balloon
            text:
              ja: 待って！
              en: Wait!
```

- `text` に言語タグをキーとするマップを書くと、言語ごとの本文になる。
- レンダリング時に言語を指定する（CLI の `--lang en`、API の `lang`）。指定がなければ `meta.lang`。レンダリング時の言語は、`writing`・禁則・`maxChars` などの言語による既定値の選択にも使う。
- 指定した言語の本文がない要素は、`meta.lang` の本文を使い、警告（`TEXT_MISSING_TRANSLATION`）を出す。
- `locales.<言語>` には `defaults`、`fonts`、`styles` を書ける。`defaults` はカスケードの段階 5 として適用し、`fonts`・`styles` は同じ名前の定義を上書きする（[3.8](03-document-format.md#38-スタイルと既定値のカスケード)）。
- 読み方向とコマ割りは言語によって変えない（左右反転版は対象外）。
- 吹き出しのサイズは言語ごとに本文に合わせて決め直す。固定サイズの吹き出しで収まらない場合は [6.7.4](06-balloons.md#674-収まらない場合) に従う。

## 7.17 組版結果の情報

組版の結果は LayoutTree（[2.4.2](02-architecture.md#242-layouttree-の要件)）に含め、次の情報を提供する。エディタでの表示や、外部ツールでの写植の差し替えに使う。

- 行（列）ごとの範囲と、含まれる文字の範囲（元の文字列の位置）
- 文字ごとの字形 ID、フォント、位置、回転、縦中横・ルビ・傍点の区別
- 適用した文字サイズ（縮小した場合はその値）と縮小率
- 自動で挿入した改行の位置
