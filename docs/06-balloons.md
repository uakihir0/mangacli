# 6. 吹き出し

## 6.1 構成

吹き出し（`type: balloon`）は、次の 4 つで構成する。

| 構成要素 | 説明 |
|---|---|
| 本体（body） | セリフを囲む図形。`shape` で形を選ぶ |
| しっぽ（tail） | 本体から話者へ向かう突起。0 本以上 |
| 本文（text） | 本体の中のセリフ。組版は [7](07-text.md) に従う |
| 連結（connect） | 他の吹き出しとのつながり（P1） |

本体としっぽは 1 つの輪郭に合成してから手描き化する。本体としっぽの境目に線は入らない（[6.6.4](#664-本体との合成)）。

```yaml
- balloon: |
    待って
    まだ話は
    終わってない
  shape: ellipse
  tail: hanako1.mouth
  at: [62%, 22%]
```

## 6.2 プロパティ

| キー | 型 | 既定値 | 説明 |
|---|---|---|---|
| `text` | 文字列 | 必須 | 本文。インラインマークアップを使える（[7.7](07-text.md#77-インラインマークアップ)） |
| `who` | キャラクター ID | - | 話者。キャラクターの設定を適用し、しっぽの向き先を決める |
| `as` | 発話の種類 | `say` | 組み込みスタイルの選択（[6.13](#613-組み込みスタイル)） |
| `shape` | Shape | `{ kind: ellipse }` | 本体の形（[6.3](#63-形状shape)） |
| `stroke` | Stroke | `{ width: 0.25mm, pen: g-pen }` | 本体としっぽの線（[6.4](#64-線stroke)） |
| `fill` | Paint | `paper` | 本体の塗り（[6.5](#65-塗りfill)） |
| `tail` | Tail \| Point \| `none` | 下記 | しっぽ（[6.6](#66-しっぽtail)） |
| `tails` | Tail[] | - | 複数のしっぽ（P1）。`tail` と同時に指定できない |
| `size` | Size \| `auto` | `auto` | 本体の外接矩形の大きさ。`auto` は本文に合わせる（[6.7](#67-サイズの決定)） |

| `maxSize` | Size | `[70%, 70%]` | `auto` のときの最大（コマの表示領域に対する割合） |
| `aspect` | 数値 \| `auto` | `auto` | 本体の縦横比（幅 / 高さ）の希望値 |
| `aspectRange` | `[最小, 最大]` | `[0.55, 1.8]` | `aspect: auto` のときに許す縦横比の範囲 |
| `padding` | Length \| `[縦, 横]` | `[0.45em, 0.9em]` | 本文と本体の内側の安全領域との間隔 |
| `textOffset` | `[dx, dy]` | `[0, 0]` | 本文の位置の微調整 |
| `textOutline` | Outline[] | - | 本文の縁取り。`shape: none` で絵の上に直接文字を置く場合に使う |
| `overflow` | `shrink` \| `grow` \| `clip` \| `error` | `auto` のときは `grow`、固定サイズのときは `shrink` | 本文が収まらない場合の処理（[6.7.4](#674-収まらない場合)） |
| `minFontScale` | 0〜1 | `0.75` | `shrink` で縮める下限 |
| `connect` | Connect \| Connect[] | - | 連結（[6.9](#69-連結と重なり)、P1） |
| `autoPlace` | `auto` \| `flow` \| `{ mode, inset, weights, threshold }` | `auto`（自動配置の実装前は `flow`） | 位置を指定しない場合の配置方法（[6.8](#68-配置)、[6.12](#612-自動配置)） |
| 組版のプロパティ | - | - | `font`、`fontSize`、`color`、`writing`、`lineHeight`、`letterSpacing`、`align`、`wrap`、`maxChars` など（[7.2](07-text.md#72-組版のプロパティ)） |
| 共通プロパティ | - | - | `at`、`place`、`anchor`、`offset`、`rotate`、`z`、`clip`（既定 `none`）など（[5.2](05-elements-and-images.md#52-共通プロパティ)） |

`rotate` は本体と本文をまとめて回転する。本体だけを傾ける場合は `shape.tilt` を使う。

## 6.3 形状（shape）

| `none` | なし | 絵の上に直接置く文字（モノローグ、心の声） | P0 |
| `burst` | 爆発 | 絶叫、爆発的な驚き | P1 |

| `path` | パス | 任意の形 | P1 |

### 6.3.2 共通パラメータ

| パラメータ | 型 | 既定値 | 説明 |
|---|---|---|---|
| `irregularity` | 0〜1 | `0.35` | 形状レベルの不規則さ（[9.3](09-hand-drawn.md#93-揺らぎの階層)）。0 で幾何学的な形 |
| `tilt` | Angle \| Range | `[-3deg, 3deg]` | 本体だけの傾き |
| `strokes` | 整数 \| `auto` | `auto` | 閉じた輪郭を何本のストロークで描くか（[9.5.2](09-hand-drawn.md#952-閉じた形状)）。`ellipse`、`round-rect`、`wavy` で使う |

### 6.3.3 ellipse（楕円）

| パラメータ | 型 | 既定値 | 説明 |
|---|---|---|---|
| `squareness` | 0〜1 | `0.12` | 0 で楕円、1 に近いほど角丸四角に近づく（超楕円の指数 n = 2 + 3 × squareness） |
| `egg` | -1〜1 | `0.06` | 上下の非対称。正で上側が膨らむ |

手描きの楕円は真円や数学的な楕円にならない。半径を角度 θ の関数として、低次の調和成分でわずかに歪める（[9.3.1](09-hand-drawn.md#931-形状レベルの不規則さ)）。

### 6.3.4 round-rect（角丸四角）・rect（四角）

| パラメータ | 型 | 既定値 | 説明 |
|---|---|---|---|
| `radius` | Length \| % | `round-rect` は短辺の 25 %、`rect` は 0 | 角の半径 |
| `ruler` | 真偽値 | `round-rect` は `false`、`rect` は `true` | 定規で引いた線にする（[9.6](09-hand-drawn.md#96-定規モード)） |
| `join` | `clean` \| `overshoot` \| `gap` | `clean` | `rect` の角の処理（枠線の `join` と同じ、[4.9](04-pages-and-panels.md#49-枠線border)） |

### 6.3.5 cloud（雲）

| パラメータ | 型 | 既定値 | 説明 |
|---|---|---|---|
| `lobes` | 整数 \| `auto` | `auto` | 膨らみの数。`auto` は周長 ÷ 7 mm（最小 7） |
| `lobeSize` | Range | `[0.75, 1.3]` | 膨らみごとの大きさの比 |
| `depth` | 0〜1 | `0.16` | 膨らみの間のくぼみの深さ（本体の半径に対する比） |

膨らみは 1 つずつ別のストロークとして描く（[9.5.3](09-hand-drawn.md#953-形状ごとの分解規則)）。

### 6.3.6 spike（トゲ）

| パラメータ | 型 | 既定値 | 説明 |
|---|---|---|---|
| `count` | 整数 \| `auto` | `auto` | トゲの数。`auto` は周長 ÷ 6 mm（最小 10） |
| `depth` | Range | `[0.22, 0.34]` | トゲの長さ（本体の半径に対する比） |
| `angleJitter` | 0〜1 | `0.3` | トゲの間隔の不揃い（等間隔に対する比） |
| `curve` | -1〜1 | `0.3` | トゲの辺の反り。正で内側へ反る（鋭く見える） |
| `inner` | `ellipse` \| `cloud` | `ellipse` | トゲの付け根を結ぶ形 |

トゲの各辺は、付け根から先端へ向かって描き、先端で抜く（細くなる）ストロークとする。手描きの叫び吹き出しの鋭さは、この抜きによって生まれる。

### 6.3.7 wavy（波）

| パラメータ | 型 | 既定値 | 説明 |
|---|---|---|---|
| `waves` | 整数 \| `auto` | `auto` | 波の数。`auto` は周長 ÷ 3.5 mm |
| `amplitude` | Length | `0.5mm` | 波の振幅 |
| `waveform` | `sine` \| `zigzag` \| `irregular` | `sine` | 波形。`zigzag` はガタガタした震え、`irregular` は不規則な震え |

### 6.3.8 none（なし）

本体を描かない。本文だけを描く。絵の上で文字を読みやすくするため、`textOutline`（例: `0.8mm white`）を併用することを推奨する。しっぽは `line` のみ指定できる（それ以外は警告 `BALLOON_TAIL_UNSUPPORTED` を出して無視）。

### 6.3.9 burst（爆発）

（P1）`spike` より大きく不規則なトゲを持つ。

| パラメータ | 型 | 既定値 | 説明 |

| `depth` | Range | `[0.2, 0.6]` | トゲの長さ |
| `secondary` | 真偽値 | `true` | 主なトゲの間に小さなトゲを入れる |

## 6.4 線（stroke）

| キー | 型 | 既定値 | 説明 |
|---|---|---|---|
| `width` | Length | `0.25mm` | 線幅（筆圧による変化の基準） |
| `color` | Color | `black` | 線の色 |
| `pen` | Pen | `g-pen` | ペン（[9.7](09-hand-drawn.md#97-ペンプリセット)） |
| `style` | `solid` \| `dashed` \| `dotted` \| `double` \| `none` | `solid` | 線の種類。`dotted`、`double` は P1 |
| `dash` | `[線, 隙間]` | `[1.6mm, 1.0mm]` | `dashed` の長さ |
| `dot` | `{ size, gap }` | `{ size: 0.45mm, gap: 0.9mm }` | `dotted` の点 |
| `double` | `{ gap, inner }` | `{ gap: 0.6mm, inner: 0.2mm }` | `double` の間隔と内側の線幅 |
| `hand` | Hand | - | 線だけの手描き設定 |

- `dashed` の各線は、入り抜きのある短いストロークとして描き、長さを ±20 % ばらつかせる。小声（ひそひそ声）の表現に使う。
- `dotted` の各点は、わずかに歪んだ小さな塗りの円として描く。
- `double` は、外側の線と、内側へ `gap` だけ離した細い線の 2 本で描く。強い強調や館内放送などの表現に使う。

## 6.5 塗り（fill）

| 値 | 表現 |
|---|---|
| `paper`（既定） | 白の吹き出し |
| `black` | 黒ベタの吹き出し（反転）。恐ろしい声、邪悪な声、テレパシーなど |
| `tone(...)` | トーンを貼った吹き出し。回想、弱い声など |
| `none` | 透明。線だけを描き、下の絵が透ける |
| 色・グラデーション | カラー原稿での色付きの吹き出し |

- 本文の `color` を指定しない場合は、塗りの平均輝度が 0.5 未満なら白、それ以外なら黒にする。
- `opacity` は吹き出し全体（本体・線・本文）に適用する。塗りだけを半透明にする場合は `fillOpacity`（0〜1、P1）を使う。

## 6.6 しっぽ（tail）

### 6.6.1 指定方法

```yaml
tail: taro1.mouth                    # 向き先だけを指定（省略記法）

tail:
  kind: wedge
  to: taro1.mouth
  width: 4mm
  bend: 0.3

tail: { direction: 110deg, length: 8mm }   # 向き先がない場合は方向と長さ

tail: none
```

### 6.6.2 プロパティ

| キー | 型 | 既定値 | 説明 |
|---|---|---|---|
| `kind` | `wedge` \| `bubbles` \| `line` \| `zigzag` \| `none` | 形状と `as` による | しっぽの種類（下表） |
| `to` | Point | 話者 | 向き先。`who` があり、同じコマに話者の画像があれば、その画像（[3.7.2](03-document-format.md#372-参照)） |
| `direction` | Angle | `100deg`（下やや左） | `to` がない場合の向き |
| `length` | Length | `to` までの距離から決める / 5 mm（`zigzag` は 7 mm） | しっぽの長さ（本体の縁から先端まで）。話者の顔（`face` の楕円）の手前で止める |
| `maxLength` | Length | 本体の短辺の 80 %（4〜14 mm に制限） | 長さの上限。向き先が遠い場合は、向きだけを合わせてこの長さで止める |
| `gap` | Length | `2mm` | 先端と向き先の点の間に残す距離（しっぽは口元に触れない） |
| `width` | Length | 本体の短辺の 30 %（2.6〜7 mm に制限） | 付け根の幅 |
| `widthScale` | 数値 | `1` | 付け根の幅の倍率。カスケードの後に掛ける（`as: shout` などで使う） |
| `bend` | -1〜1 | `0.15` | しっぽ全体の曲がり。正で時計回りに曲がる |
| `sideCurve` | 0〜1 | `0.25` | 両側の辺の内側への反り。大きいほど先端が鋭く見える |
| `root` | `auto` \| Angle | `auto` | 本体のどこから出すか。`auto` は本体の中心から向き先への方向。角度は本体の中心から見た方向 |
| `offscreen` | `top` \| `right` \| `bottom` \| `left` | - | 画面外の話者。コマの指定した辺の外へ向け、枠で切る（P1） |
| `count` | 整数 | `3` | `bubbles` の泡の数 |
| `bubbleSize` | Length | 本体の短辺の 20 %（1.5〜5 mm に制限）。顔までの距離に収まらない場合は 55 % まで縮める | `bubbles` の最初の泡の直径 |
| `shrink` | 0〜1 | `0.62` | `bubbles` の泡ごとの縮小率 |
| `segments` | 整数 | `3` | `zigzag` の折れの数 |

| `kind` | 形 | 既定で使う形状・`as` | 優先度 |
|---|---|---|---|
| `wedge` | 両側が曲線のくさび形 | `ellipse`、`round-rect`、`spike`、`wavy` など | P0 |
| `bubbles` | 小さくなっていく泡の連なり | `cloud`（`as: think`） | P0 |
| `line` | 先端に向けて細くなる 1 本の線 | `none` | P1 |
| `zigzag` | 稲妻形 | `electronic` | P1 |
| `none` | しっぽなし | `rect`、`flash`（`as: narration`、`monologue`） | P0 |

### 6.6.3 幾何の計算（wedge）

1. 付け根の中心 R: 本体の中心から向き先（または `direction`）への半直線と、本体の輪郭との交点。`root` に角度を指定した場合は、その方向の交点。
2. 付け根の両端 A、B: 輪郭上で R から弧長 ±`width` / 2 の点。
3. 先端 T: R から向き先へ向かって `length` 進んだ点。`to` がある場合、`length` の既定は「R から向き先までの距離 − `gap`」を `maxLength` で制限した値。
4. 中心線 R→T を、`bend` に応じた 2 次ベジェ曲線にする（制御点を中心線の中点から法線方向に `bend` × `length` × 0.5 ずらす）。
5. 辺 A→T と B→T は、中心線に沿って先端へ収束する曲線とし、`sideCurve` に応じて内側へ反らせる。
6. 向き先が本体の内側にある場合は、しっぽを描かず警告（`BALLOON_TAIL_TARGET_INSIDE`）を出す。

### 6.6.4 本体との合成

1. 本体の輪郭（形状レベルの不規則さを適用済み）としっぽの輪郭を、ポリゴンの和として合成し、1 つの閉じた輪郭にする。
2. 塗りは合成した輪郭で行う。
3. 線は、合成した輪郭をストロークに分解して描く（[9.5](09-hand-drawn.md#95-形状からストロークへの分解)）。しっぽの付け根（凹の角）でストロークを区切り、しっぽの辺は付け根から先端へ向かって描いて先端で抜く。
4. 凹の角でストロークがわずかに突き抜ける場合、吹き出しの内側に入った部分は描かない（ホワイトで修正したように扱う、[9.5.4](09-hand-drawn.md#954-角と閉じ目)）。

`bubbles` の泡は本体と合成せず、それぞれ独立した小さな楕円として描く。

## 6.7 サイズの決定

### 6.7.1 流れ

1. 本文を組版する（[7](07-text.md)）。行の長さは `maxChars` などの改行の規則に従う。
2. 組版結果から、本文の各行（縦書きでは各列）の矩形の 4 隅の点を求め、`padding` だけ外側へ広げる。ルビ・傍点の範囲も含める。
3. 形状ごとの方法で、これらの点をすべて内側に含む最小の本体を求める（6.7.2）。
4. `minSize`、`maxSize` で制限する。
5. 本文を、本体の本文領域の中央に置き、`textOffset` を加える。

### 6.7.2 形状への当てはめ

楕円の場合、本体の中心から見た点 (xᵢ, yᵢ) をすべて含む半径 (a, b) は、次の条件を満たす。

```text
(xᵢ / a)² + (yᵢ / b)² ≤ 1   （すべての i）
```

縦横比 r = a / b を `aspectRange` の範囲で動かし、面積 π·a·b が最小になる r を黄金分割探索で求める（`aspect` を指定した場合はその値に固定する）。r を固定すると b = maxᵢ √((xᵢ / r)² + yᵢ²) で決まる。

この解析解は**初期値**とする。実際の輪郭は、形状レベルの不規則さ（調和成分、`egg`、`squareness`）と `tilt` によって楕円からずれるため、最終的な大きさは次の手順で決める。

1. 初期値の大きさで、形状レベルの不規則さと `tilt` を適用した本文の安全領域（楕円では輪郭そのものを、経路の揺らぎの振幅 `wobble.amplitude` と線幅の半分だけ内側に縮めた形）を作る。
2. すべての点がその内側に入るまで、縦横比を保って縮尺を二分探索で大きくする（入りすぎている場合は小さくする）。許容誤差は 0.05 mm。
3. 不規則さは要素のシードで決まるため、大きさを変えても輪郭の形の比率は変わらない（調和成分の位相と振幅比は大きさに依存しない）。

その他の形状は、形状の定義が提供する「本文の安全領域」（例: `spike` はトゲの付け根を結ぶ内側の形、`cloud` は膨らみのくぼみを結ぶ内側の形）について、同じ方法で縮尺と縦横比を求める。形状の定義が専用の当てはめ関数を持たない場合は、安全領域の内外判定を使った縮尺の二分探索だけで求める。いずれの形状でも、包含の判定は不規則さと `tilt` を適用した後の形で行う（[14.2.2](14-quality.md#1422-不変条件) の不変条件）。

### 6.7.3 固定サイズ

`size` を指定した場合は、本体の大きさを固定し、本文の安全領域の中で組版する。縦書きでは安全領域の高さを列の長さの上限、横書きでは幅を行の長さの上限とする。

### 6.7.4 収まらない場合

| `overflow` | 処理 |
|---|---|
| `grow` | 本体を大きくする。`maxSize` を超える場合は、`shrink` と同じ処理を行い、それでも収まらなければ `maxSize` を超えて大きくし、警告（`BALLOON_TOO_LARGE`）を出す |
| `shrink` | 文字サイズを `minFontScale` まで段階的（元の大きさの 5 % ずつ）に縮める。縮めて収まった場合は情報（`TEXT_SHRUNK`）を出す。それでも収まらなければ `clip` と同じ処理を行う |
| `clip` | はみ出した本文を本体の形で切り、警告（`TEXT_OVERFLOW`）を出す |
| `error` | エラー（`TEXT_OVERFLOW`）にする |

## 6.8 配置

| 方法 | 指定 | 優先度 |
|---|---|---|
| 座標 | `at`（+ `anchor`、`offset`） | P0 |
| 寄せ | `place`（+ `inset`） | P0 |
| 自動配置 | 位置を指定しない（`dialogue` の行を含む） | P1（6.12） |
| 流し込み | 位置を指定しない（自動配置の実装前、または `autoPlace: flow`） | P0 |

**流し込み**は、位置を指定していない吹き出しを、コマの上端の読み始め側（`readingDirection: rtl` なら右上）から読み方向へ、コマの吹き出しの順序（[6.11](#611-セリフの省略記法dialogue)）で 1 mm の間隔で並べる。コマの幅に収まらなければ下の段に送る。自動配置を実装した後も、`autoPlace: flow`（コマ・ページ・ドキュメントの `defaults.balloon` に書ける）で選べる。

## 6.9 連結と重なり

（P1）

### 6.9.1 連結（connect）

同じ話者の続きのセリフを、吹き出し同士をつないで表す。

```yaml
- balloon: そうか
  id: b1
  at: [70%, 15%]
- balloon: やっぱり君だったのか
  at: [45%, 30%]
  connect: { to: b1, style: neck }
```

| キー | 型 | 既定値 | 説明 |
|---|---|---|---|
| `to` | 吹き出しの ID | 必須 | つなぐ相手 |
| `style` | `neck` \| `overlap` \| `line` | `neck` | `neck` はくびれでつなぐ。`overlap` は重なった本体の輪郭を合成する。`line` は短い線でつなぐ |
| `width` | Length \| % | 小さいほうの本体の短辺の 35 % | `neck` のくびれの幅 |

- `neck`: 2 つの本体の中心を結ぶ線に沿った帯（幅 `width`）を作り、2 つの本体と和を取って 1 つの輪郭にする。輪郭の凹の角でストロークを区切る。
- `overlap`: 2 つの本体の和を取る。本体が重なっていない場合は警告（`BALLOON_CONNECT_DISJOINT`）を出し、`neck` として扱う。
- `line`: 本体の縁同士を結ぶ 1 本の線を描く。
- 連結した吹き出しの本文はそれぞれの本体に置く。連結した吹き出しは、構成する吹き出しの `z` の最大値でまとめて描く。

### 6.9.2 重なり

連結しない吹き出し同士が重なる場合は、`z` が等しければ、**吹き出しの順序で先の吹き出し（先に読む吹き出し）を上に描く**（[4.12](04-pages-and-panels.md#412-描画順)）。先の吹き出しの線はすべて見え、後の吹き出しは先の吹き出しの後ろに隠れる。重なった吹き出しは手前のものから読むという漫画の慣習に合わせる。後の吹き出しを手前にしたい場合は `z` を大きくする。重なりによって本文が隠れる場合は警告（`BALLOON_TEXT_HIDDEN`）を出す。

## 6.10 コマの枠との関係

| 表現 | 指定 |
|---|---|
| 枠にかかる吹き出し（枠線の上に描く） | 既定（`clip: none`） |
| 枠で切れる吹き出し | `clip: panel`。枠線は吹き出しの上に描かれる |
| コマをまたぐ吹き出し | ページの `layers` に置く、またはコマの `layers` に置いて `coords: page` で配置する |

- 本文が安全領域（[4.1](04-pages-and-panels.md#41-ページの幾何)）の外に出る場合は警告（`TEXT_OUTSIDE_SAFE_AREA`）。
- `clip: panel` で本文の一部が切れる場合は警告（`TEXT_CLIPPED`）。

## 6.11 セリフの省略記法（dialogue）

（P1）

コマの `dialogue` に、セリフを読み順に並べる。各行は吹き出しに展開する。

```yaml
panels:
  - layers:
      - image: taro-surprised
        id: taro1
      - image: hanako-smile
        id: hanako1
    dialogue:
      - taro: えっ!?
      - hanako: |
          ふふ
          びっくりした？
      - { who: taro, as: think, text: なんでここに…… }
      - { as: narration, text: その日の放課後 }
      - { who: teacher, as: offscreen, from: right, text: 早く帰りなさい！ }
```

| キー | 型 | 説明 |
|---|---|---|
| `<キャラクター ID>: 本文` | - | 省略形。`{ who: <ID>, text: 本文 }` と同じ。`{ taro: えっ!?, as: shout }` のように他のキーと併記できる |
| `who` | キャラクター ID | 話者 |
| `text` | 文字列 | 本文 |
| `as` | 発話の種類 | 既定 `say`。`narration` では話者を省略できる |
| `from` | `top` \| `right` \| `bottom` \| `left` | `as: offscreen` の話者の方向（`tail.offscreen` に展開する） |
| その他 | 吹き出しのプロパティ | `id`、`at`、`shape`、`fontSize` など、吹き出しのすべてのプロパティを書ける |

- 展開した吹き出しは、コマの `layers` の後ろに、行の順で追加する。ID は `<コマ ID>-d<行の番号>` とする。
- **コマの吹き出しの順序**は、展開した後の `layers` の中の吹き出しの順（`layers` に書いた吹き出し、続いて `dialogue` の行）とする。この順序を、読み順、流し込み・自動配置の処理順、重なりの上下、読み順の検証、セリフ一覧のすべてで使う。
- 位置を指定しない行は、自動配置（6.12）で位置を決める。
- `who` の話者の画像が同じコマにない場合は、しっぽを `direction` の既定値で描き、情報（`DIALOGUE_SPEAKER_NOT_IN_PANEL`）を出す。
- `who` に未定義のキャラクター ID を書いた場合はエラー（`REF_NOT_FOUND`）。

## 6.12 自動配置

（P1）

位置を指定していない吹き出しを、読みやすさの規則に従って自動で置く。

### 6.12.1 入力

- 配置領域: コマの表示領域を `autoPlace.inset`（既定 1.5 mm、B5 基準で比例）だけ縮め、安全領域と重ねた矩形。
- 障害物:
  - 位置を明示した吹き出し・地の文字・描き文字（重なりを強く避ける）
  - 画像の素材の領域 `face`、`avoid`（強く避ける）
  - 画像のアンカー `mouth`（覆ってはならない）
  - 画像の外接矩形（弱く避ける）
- 配置する吹き出しの列: コマの吹き出しの順序（6.11）のうち、位置を指定していないもの。

### 6.12.2 手順

1. 吹き出しの大きさを 6.7 で決める。
2. 配置領域に、間隔 `max(1.5 mm, 配置領域の短辺 / 28)` の格子で中心の候補点を作る（寸法は B5 基準で比例）。
3. 列の先頭から順に、各候補点について次の費用を計算し、最小の候補に置く。置いた吹き出しは、以降の吹き出しの障害物になる。

| 費用の項 | `weights` のキー | 内容 | 既定の重み |
|---|---|---|---|
| 読み順 | `order` | 読み順の座標 s（吹き出しの上端で測る。`rtl` では s = 0.8 × y − 0.2 × x、`ltr` では s = 0.8 × y + 0.2 × x。x、y は配置領域で 0〜1 に正規化）が、直前の吹き出し（位置を指定したものを含む）の s + 0.02 より小さい量 | 120 |
| 読み始め | `start` | 先頭の吹き出しの、読み始めの角（`rtl` なら右上）からの距離 | 4 |
| 重なり | `overlap` | 他の吹き出し・文字との重なりの面積の比 | 50 |
| 回避領域 | `avoid` | `face`、`avoid` との重なりの比。`face` は外接矩形に内接する楕円（12 % 広げる）として測る。`mouth` を覆う場合は 1000 | 60 |
| 人物 | `figure` | キャラクターの画像の不透明な部分（シルエット）を覆う比 | 6 |
| 話者との距離 | `speaker` | 話者のアンカーとの距離が、吹き出しの半径の 1.6 倍から離れるほど大きい | 1.5 |
| しっぽ | `tail` | 話者へのしっぽの経路が、置いた吹き出しと交わるごとに加える | 4 |
| 上寄せ | `top` | 中心の y の正規化値（上ほど小さい） | 1 |
| はみ出し | `outside` | 配置領域の外に出る面積の比 | 30 |
| 画面外の話者 | `offscreen` | 画面外の話者（`tail.offscreen`）の側の辺から離れる距離の比 | 8 |

4. 同点の候補は、読み始めの角に近い順（`rtl` では上、次に右）で選ぶ。
5. 最小の費用がしきい値（`autoPlace.threshold`、既定 25）を超える場合は、最小の費用の候補に置き、警告（`BALLOON_NO_SPACE`）を出す（文字サイズを縮めての再試行は今後の拡張）。

重みとしきい値は `defaults.balloon.autoPlace.weights`、`autoPlace.threshold` で変更できる。結果は決定的でなければならない。

### 6.12.3 読み順の検証

自動配置か手動配置かにかかわらず、1 つのコマの中の吹き出しについて、コマの吹き出しの順序（6.11）と位置から推定した読み順が食い違う場合は、情報（`BALLOON_ORDER_MISMATCH`）を出す。推定は、コマの読み順の規則（[4.11](04-pages-and-panels.md#411-読み順) の 3.）を吹き出しの外接矩形に適用して行う。
