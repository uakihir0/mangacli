# 6. 吹き出し

## 6.1 構成

吹き出し（`type: balloon`）は、次の 4 つで構成する。

| 構成要素 | 説明 |
|---|---|
| 本体（body） | セリフを囲む図形。`shape` で形を選ぶ |
| しっぽ（tail） | 本体から話者へ向かう突起。0 本以上 |
| 本文（text） | 本体の中のセリフ。組版は [7](07-text.md) に従う |
| 連結（connect） | 他の吹き出しとのつながり（P1） |

本体としっぽは 1 つの輪郭に合成してから手描き化する。本体としっぽの境目に線は入らない（[6.6.4](#664-本体との合成)）。

```yaml
- balloon: |
    待って
    まだ話は
    終わってない
  shape: ellipse
  tail: hanako1.mouth
  at: [62%, 22%]
```

## 6.2 プロパティ

| キー | 型 | 既定値 | 説明 |
|---|---|---|---|
| `text` | 文字列 | 必須 | 本文。インラインマークアップを使える（[7.7](07-text.md#77-インラインマークアップ)） |
| `who` | キャラクター ID | - | 話者。キャラクターの設定を適用し、しっぽの向き先を決める |
| `as` | 発話の種類 | `say` | 組み込みスタイルの選択（[6.13](#613-組み込みスタイル)） |
| `shape` | Shape | `{ kind: ellipse }` | 本体の形（[6.3](#63-形状shape)） |
| `stroke` | Stroke | `{ width: 0.25mm, pen: g-pen }` | 本体としっぽの線（[6.4](#64-線stroke)） |
| `fill` | Paint | `paper` | 本体の塗り（[6.5](#65-塗りfill)） |
| `autoConnect` | 真偽値 | `true` | 同じ話者の続けての自動配置の吹き出しが 4 bmm 以内に並んだ場合、`connect: { to: 直前の吹き出し, style: neck }` として 1 つのしっぽにまとめる |
| `halo` | Length \| `none` | `0.3bmm` | 線の外側に付ける塗り色（不透明な単色のときのみ）のふち。黒い絵やベタに重なっても輪郭が見えるようにする |
| `tail` | Tail \| Point \| `none` | 下記 | しっぽ（[6.6](#66-しっぽtail)） |
| `tails` | Tail[] | - | 複数のしっぽ（P1）。`tail` と同時に指定できない |
| `size` | Size \| `auto` | `auto` | 本体の外接矩形の大きさ。`auto` は本文に合わせる（[6.7](#67-サイズの決定)） |
| `minSize` | Size | `[8mm, 8mm]` | `auto` のときの最小 |
| `maxSize` | Size | `[75%, 80%]` | `auto` のときの最大（コマの表示領域に対する割合） |
| `aspect` | 数値 \| `auto` | `auto` | 本体の縦横比（幅 / 高さ）の希望値 |
| `aspectRange` | `[最小, 最大]` | `[0.55, 1.8]` | `aspect: auto` のときに許す縦横比の範囲 |
| `padding` | Length \| `[縦, 横]` | `[0.6em, 0.8em]` | 本文と本体の内側の安全領域との間隔 |
| `textOffset` | `[dx, dy]` | `[0, 0]` | 本文の位置の微調整 |
| `textOutline` | Outline[] | - | 本文の縁取り。`shape: none` で絵の上に直接文字を置く場合に使う |
| `overflow` | `shrink` \| `grow` \| `clip` \| `error` | `auto` のときは `grow`、固定サイズのときは `shrink` | 本文が収まらない場合の処理（[6.7.4](#674-収まらない場合)） |
| `minFontScale` | 0〜1 | `0.75` | `shrink` で縮める下限 |
| `connect` | Connect \| Connect[] | - | 連結（[6.9](#69-連結と重なり)、P1） |
| `autoPlace` | `auto` \| `flow` \| `{ mode, inset, weights, threshold }` | `auto`（自動配置の実装前は `flow`） | 位置を指定しない場合の配置方法（[6.8](#68-配置)、[6.12](#612-自動配置)） |
| 組版のプロパティ | - | - | `font`、`fontSize`、`color`、`writing`、`lineHeight`、`letterSpacing`、`align`、`wrap`、`maxChars` など（[7.2](07-text.md#72-組版のプロパティ)） |
| 共通プロパティ | - | - | `at`、`place`、`anchor`、`offset`、`rotate`、`z`、`clip`（既定 `auto`）など（[5.2](05-elements-and-images.md#52-共通プロパティ)） |

`rotate` は本体と本文をまとめて回転する。本体だけを傾ける場合は `shape.tilt` を使う。

## 6.3 形状（shape）

### 6.3.1 形状の一覧

| `kind` | 名称 | 主な用途 | 優先度 |
|---|---|---|---|
| `ellipse` | 楕円 | 通常のセリフ（**既定**） | P0 |
| `round-rect` | 角丸四角 | 落ち着いたセリフ、説明 | P0 |
| `rect` | 四角 | ナレーション、モノローグ | P0 |
| `cloud` | 雲（もくもく） | 心の声、思考、回想、夢 | P0 |
| `spike` | トゲ | 叫び、大声、驚き | P0 |
| `wavy` | 波（ふるえ） | 恐怖・寒さ・動揺で震える声、弱々しい声 | P0 |
| `none` | なし | 絵の上に直接置く文字（モノローグ、心の声） | P0 |
| `burst` | 爆発 | 絶叫、爆発的な驚き | P1 |
| `flash` | フラッシュ | 衝撃を受けた心の声、強調する独白 | P1 |
| `electronic` | 電子音 | 電話・テレビ・機械・スピーカー越しの声 | P1 |
| `hexagon` | 角張り（六角形） | ぶっきらぼうな声、低く平板な声（直線の辺と丸めた角。`as: gruff`）。`corners` で角の数 | P1 |
| `polygon` | 多角形 | 任意の形 | P1 |
| `path` | パス | 任意の形 | P1 |
| `icicle` | つらら | 冷たい声 | P2 |
| `flower` | 花 | ときめき、嬉しい声 | P2 |

### 6.3.2 共通パラメータ

| パラメータ | 型 | 既定値 | 説明 |
|---|---|---|---|
| `irregularity` | 0〜1 | `0.12` | 形状レベルの不規則さ（[9.3](09-hand-drawn.md#93-揺らぎの階層)）。0 で幾何学的な形 |
| `tilt` | Angle \| Range | `[-1.5deg, 1.5deg]` | 本体だけの傾き |
| `strokes` | 整数 \| `auto` | `auto` | 閉じた輪郭を何本のストロークで描くか（[9.5.2](09-hand-drawn.md#952-閉じた形状)）。`ellipse`、`round-rect`、`wavy` で使う |

### 6.3.3 ellipse（楕円）

| パラメータ | 型 | 既定値 | 説明 |
|---|---|---|---|
| `squareness` | 0〜1 | 本文から決める | 0 で楕円、1 に近いほど角丸四角に近づく（超楕円の指数 n = 2 + 3 × squareness）。指定しない場合は本文の形から決める: 短い本文は 0（楕円）、行（列）が多く長さのそろった塊ほど大きく（中心に四角い領域がある形）、1 列の細長い本文は 0.25 前後（カプセル形）。0〜0.3 に制限 |
| `egg` | -1〜1 | `0.06` | 上下の非対称。正で上側が膨らむ |

手描きの楕円は真円や数学的な楕円にならない。半径を角度 θ の関数として、低次の調和成分でわずかに歪める（[9.3.1](09-hand-drawn.md#931-形状レベルの不規則さ)）。

### 6.3.4 round-rect（角丸四角）・rect（四角）

| パラメータ | 型 | 既定値 | 説明 |
|---|---|---|---|
| `radius` | Length \| % | `round-rect` は短辺の 25 %、`rect` は 0 | 角の半径 |
| `ruler` | 真偽値 | `round-rect` は `false`、`rect` は `true` | 定規で引いた線にする（[9.6](09-hand-drawn.md#96-定規モード)） |
| `join` | `clean` \| `overshoot` \| `gap` | `clean` | `rect` の角の処理（枠線の `join` と同じ、[4.9](04-pages-and-panels.md#49-枠線border)） |

### 6.3.5 cloud（雲）

| パラメータ | 型 | 既定値 | 説明 |
|---|---|---|---|
| `lobes` | 整数 \| `auto` | `auto` | 膨らみの数。`auto` は周長 ÷ 7 mm（最小 7） |
| `lobeSize` | Range | `[0.55, 1.5]` | 膨らみごとの大きさの比。隣同士（最後と最初も）は約 20 % 以上離す（指定範囲で可能な場合） |
| `depth` | 0〜1 | `0.16` | 膨らみの間のくぼみの深さ（本体の半径に対する比） |

膨らみは 1 つずつ別のストロークとして描く（[9.5.3](09-hand-drawn.md#953-形状ごとの分解規則)）。

### 6.3.6 spike（トゲ）

| パラメータ | 型 | 既定値 | 説明 |
|---|---|---|---|
| `count` | 整数 \| `auto` | `auto` | トゲの数。`auto` は周長 ÷ 5 bmm（最小 10） |
| `depth` | 数値 \| Range | 未指定時は `0.2` 相当の ±10% | 未指定なら約 3 bmm（2.7〜3.3 bmm）。明示時は従来どおり平均半径に対する比（数値は ±20%、Range は指定範囲） |
| `angleJitter` | 0〜1 | `0.15` | 周長上の 1 ピッチに対する位置の揺れ幅（±半幅） |
| `curve` | -1〜1 | `0.1` | トゲの辺の反り。正で内側へ反る（鋭く見える） |
| `inner` | `ellipse` \| `cloud` | `ellipse` | トゲの付け根を結ぶ形 |

トゲの各辺は、付け根から先端へ向かって描き、先端で抜く（細くなる）ストロークとする。手描きの叫び吹き出しの鋭さは、この抜きによって生まれる。

`spike` / `burst` は芯の輪郭に沿った距離で等間隔に並べ、局所的な外向き法線へ伸ばす。付け根は芯の上に置き、位置の揺れは 1 ピッチの ±3% 以内とする。長いアクセント針は自動で混ぜない。`bmm` は基準判型に対して拡縮する単位なので、本文量で本体が大きくなってもトゲの長さは変わらない。`shout` / `scream` の自動 `wedge` しっぽは芯から通常のトゲの約 1.5 倍まで伸ばし、1 本のトゲとして馴染ませる。明示したしっぽの長さや上限は優先する。

### 6.3.7 wavy（波）

| パラメータ | 型 | 既定値 | 説明 |
|---|---|---|---|
| `waves` | 整数 \| `auto` | `auto` | 波の数。`auto` は周長 ÷ 3.5 mm |
| `amplitude` | Length | `0.5mm` | 波の振幅 |
| `waveform` | `sine` \| `zigzag` \| `irregular` | `sine`（`as: tremble` は `irregular`） | `zigzag` は角ばった震え、`irregular` は波の深さと間隔が変わる、なめらかな震え |

### 6.3.8 none（なし）

本体を描かない。本文だけを描く。絵の上で文字を読みやすくするため、`textOutline`（例: `0.8mm white`）を併用することを推奨する。しっぽは `line` のみ指定できる（それ以外は警告 `BALLOON_TAIL_UNSUPPORTED` を出して無視）。

### 6.3.9 burst（爆発）

（P1）`spike` より長く鋭い、均一なトゲを持つ。

| パラメータ | 型 | 既定値 | 説明 |
|---|---|---|---|
| `count` | 整数 \| `auto` | `auto` | 主なトゲの数（周長 ÷ 6.5 bmm、最小 8） |
| `depth` | 数値 \| Range | 未指定時は `0.4` 相当の ±10% | 未指定なら約 5 bmm（4.5〜5.5 bmm）。明示時の比率指定は `spike` と同じ |
| `angleJitter` | 0〜1 | `0.2` | 周長上の 1 ピッチに対する位置の揺れ幅（±半幅） |
| `curve` | -1〜1 | `0.05` | トゲの辺の反り |
| `secondary` | 真偽値 | `false` | 一部のトゲを短い副トゲにする |

### 6.3.10 flash（フラッシュ）

（P1）輪郭線を持たず、ウニフラッシュ（[8.4](08-effects.md#84-ウニフラッシュuni-flash)）と同じ放射状の短い線で縁を作る。内側は `fill` で塗る。

`！！` や `！？` だけを 1 行で置く場合は、字形を太くしてフラッシュの中心に合わせて拡大する。通常のセリフや三点リーダーには適用しない。`fontScale` を指定すると自動拡大を、`weight` を指定すると自動の太字化を行わない。この反応のフラッシュは、`clip: auto` または `clip: panel` でコマに収まる場合、放射線も枠の内側に置く。

| パラメータ | 型 | 既定値 | 説明 |
|---|---|---|---|
| `count` | 整数 \| `auto` | `auto` | 線の数（周長 ÷ 1.2 mm） |
| `lineLength` | Range | `[2mm, 6mm]` | 線の長さ |
| `thickness` | Range | `[0.1mm, 0.3mm]` | 線の太さ |

### 6.3.11 electronic（電子音）

（P1）等間隔のギザギザで囲んだ本体。既定のしっぽ `zigzag`（稲妻形）は、本体と同じ線幅で描く。

| パラメータ | 型 | 既定値 | 説明 |
|---|---|---|---|
| `corners` | 整数 | 自動（山の幅が約 `0.5em`） | ギザギザの山の数（最小 5） |
| `jag` | 0〜1 | `0.25` | ギザギザの深さ。`0` ではギザギザなし |

### 6.3.12 polygon / path

（P1）

| パラメータ | 型 | 説明 |
|---|---|---|
| `points` | `[u, v][]` | `polygon` の頂点。本体の外接矩形内の相対座標（0〜1） |
| `d` | 文字列 | `path` の SVG パス。座標は 0〜1 の単位正方形 |
| `textArea` | Rect（相対） | 本文を置く領域。既定は外接矩形の 15 %〜85 % |

### 6.3.13 icicle / flower

（P2）予約のみ。`icicle` は本体の下側につららが垂れる形、`flower` は花びら状の膨らみを持つ形とする。

## 6.4 線（stroke）

| キー | 型 | 既定値 | 説明 |
|---|---|---|---|
| `width` | Length | `0.25mm` | 線幅（筆圧による変化の基準） |
| `color` | Color | `black` | 線の色 |
| `pen` | Pen | `g-pen` | ペン（[9.7](09-hand-drawn.md#97-ペンプリセット)） |
| `style` | `solid` \| `dashed` \| `dotted` \| `double` \| `none` | `solid` | 線の種類。`dotted`、`double` は P1 |
| `dash` | `[線, 隙間]` | `[線幅 × 4, 線幅 × 2.5]` | `dashed` の長さ。明示した長さはそのまま使う |
| `dot` | `{ size, gap }` | `{ size: 0.45mm, gap: 0.9mm }` | `dotted` の点 |
| `double` | `{ gap, inner }` | `{ gap: 0.6mm, inner: 0.2mm }` | `double` の間隔と内側の線幅 |
| `hand` | Hand | - | 線だけの手描き設定 |

- `dashed` は指定線幅の 65 % の細さで描く。省略時の線と隙間は、この描画線幅の 4 倍と 2.5 倍。各線は入り抜きのある短いストロークとし、長さを ±20 % ばらつかせ、閉じた輪郭全体に収まるよう調整する（始点にも同じ隙間を保つ）。尖ったしっぽは先端から両側へ対称に配分する。小声（ひそひそ声）の表現に使う。
- `dotted` の各点は、わずかに歪んだ小さな塗りの円として描く。
- `double` は、外側の線と、内側へ `gap` だけ離した細い線の 2 本で描く。強い強調や館内放送などの表現に使う。

## 6.5 塗り（fill）

| 値 | 表現 |
|---|---|
| `paper`（既定） | 白の吹き出し |
| `black` | 黒ベタの吹き出し（反転）。恐ろしい声、邪悪な声、テレパシーなど |
| `tone(...)` | トーンを貼った吹き出し。回想、弱い声など |
| `none` | 透明。線だけを描き、下の絵が透ける |
| 色・グラデーション | カラー原稿での色付きの吹き出し |

- 本文の `color` を指定しない場合は、塗りの平均輝度が 0.5 未満なら白、それ以外なら黒にする。
- `tone(...)` は白で下の絵を抜いてからトーンを重ねる。網点の隙間から下の絵は透けない（モノクロ印刷でも同じ）。
- `opacity` は吹き出し全体（本体・線・本文）に適用する。塗りだけを半透明にする場合は `fillOpacity`（0〜1、P1）を使う。

## 6.6 しっぽ（tail）

### 6.6.1 指定方法

```yaml
tail: taro1.mouth                    # 向き先だけを指定（省略記法）

tail:
  kind: wedge
  to: taro1.mouth
  width: 4mm
  bend: 0.3

tail: { direction: 110deg, length: 8mm }   # 向き先がない場合は方向と長さ

tail: none
```

### 6.6.2 プロパティ

| キー | 型 | 既定値 | 説明 |
|---|---|---|---|
| `kind` | `wedge` \| `bubbles` \| `line` \| `zigzag` \| `none` | 形状と `as` による | しっぽの種類（下表） |
| `to` | Point | 話者 | 向き先。`who` があり、同じコマに話者の画像があれば、その画像（[3.7.2](03-document-format.md#372-参照)） |
| `direction` | Angle | `100deg`（下やや左） | `to` がない場合の向き |
| `length` | Length | `to` までの距離から決める（4.5 bmm 以上。話者の顔が本体のすぐ横にあっても、しっぽが向きを示せる長さを保つ） / 4.5 bmm（`zigzag` は 11 bmm） | しっぽの長さ（本体の縁から先端まで）。話者の顔（`face` の矩形）の `gap` 手前で止める |
| `maxLength` | Length | 向き先（`to`・`who`）があれば本体の短辺の 50 %（6〜12 bmm に制限。トゲ・爆発の本体と画面外は下の値）、なければ本体の短辺の 40 %（4.5〜9 bmm に制限） | 長さの上限。しっぽは話者まで伸ばす針ではなく、口元を指していると読めるだけの短い三角形にする。向き先が遠い場合は、向きだけを合わせてこの長さで止める。そのとき先端が止まるべき点まで 20 bmm 以上残れば `BALLOON_TAIL_SHORT` を通知する |
| `gap` | Length | `2mm` | 先端と向き先の点の間に残す距離（しっぽは口元に触れない） |
| `width` | Length | 本体の短辺の 8.7 %（1.07〜1.87 bmm に制限）。`wedge` はこれを下限に、本体の短辺の 1/9（`length` の 0.4 倍以下）。`zigzag` はこの基準幅の 1.5 倍 | 付け根の幅。明示した幅を優先する。漫画のしっぽは付け根から細く鋭い（先端は 0.1 bmm 以下） |
| `curl` | 真偽値 | `true` | 話者がいる `wedge` のしっぽの中心線を円弧にする。円の中心は話者の顔（`face` 領域、なければ向き先）の側に置き、しっぽは本体から出た向きから顔の方へ曲がる（曲がりは顔の方向との角度の 0.85 倍、最大 1 rad）。本体が顔の矩形の外にあるとき、曲がりで先端が矩形の `gap` 手前を越えるなら、曲がりを 3/4・1/2・1/4 と弱め、それでも越えるならまっすぐにする。`false` で `bend` による曲がりに戻す |
| `allowVertical` | 真偽値 | `false` | `false` では、真下・真上（鉛直から 40° 以内）を向くしっぽを左下・右下（左上・右上）の 40° へ回し、本体の横（既定は左寄り）から出す。向き先があれば、付け根だけを横へ移し、先端は向き先へ向ける。雲形・画面外のしっぽには適用しない |
| `widthScale` | 数値 | `1` | 付け根の幅の倍率。カスケードの後に掛ける（`as: shout` などで使う） |
| `bend` | -1〜1 | `0.15` | しっぽ全体の曲がり。正で時計回りに曲がる |
| `sideCurve` | 0〜1 | `0.25` | 両側の辺の内側への反り。大きいほど先端が鋭く見える |
| `root` | `auto` \| Angle | `auto` | 本体のどこから出すか。`auto` は本体の中心から向き先への方向。角度は本体の中心から見た方向 |
| `offscreen` | `top` \| `right` \| `bottom` \| `left` | - | 画面外の話者。`as: offscreen` で辺を省略すると最も近い辺を使う。`from` で指定した場合も同じ。尾は `maxLength` にかかわらず話者側のコマ枠まで伸ばし、枠で切れた部分は開いた形にする。枠に届かない `length` は無視して延長し、`BALLOON_OFFSCREEN_LENGTH_IGNORED` を警告する。`clip: auto` ではコマ間の枠でも切る（P1） |
| `count` | 整数 | `3` | `bubbles` の泡の数 |
| `bubbleSize` | Length | 本体の短辺の 20 %（1.5〜5 mm に制限）。顔までの距離に収まらない場合は 55 % まで縮める | `bubbles` の最初の泡の直径 |
| `shrink` | 0〜1 | 未指定時は直径比 `1 → 0.6 → 0.35 → 0.22`（以後は約 0.63 倍） | 指定時は各泡に同じ縮小率を適用 |
| `segments` | 整数 | `3` | `zigzag` の直線区間の数（既定では 2 回折れる） |

| `kind` | 形 | 既定で使う形状・`as` | 優先度 |
|---|---|---|---|
| `wedge` | 両側が曲線のくさび形 | `ellipse`、`round-rect`、`spike`、`wavy` など | P0 |
| `bubbles` | 小さくなっていく泡の連なり | `cloud`（`as: think`） | P0 |
| `line` | 先端に向けて細くなる 1 本の線 | `none` | P1 |
| `zigzag` | 稲妻形 | `electronic` | P1 |
| `none` | しっぽなし | `rect`、`flash`（`as: narration`、`monologue`） | P0 |

### 6.6.3 幾何の計算（wedge）

1. 付け根の中心 R: 本体の中心から向き先（または `direction`）への半直線と、本体の輪郭との交点。`root` に角度を指定した場合は、その方向の交点。
2. 付け根の両端 A、B: 輪郭上で R から前後へたどり、R との直線距離が初めて `width` / 2 になる点。トゲ・爆発の自動幅は、R を挟む谷の間のトゲひとつだけを置き換え、両側のトゲを残す。付け根の実幅は本体の短辺の 1/9 以下に収める（明示した `width` は優先する）。
3. 先端 T: R から向き先へ向かって `length` 進んだ点。`to` がある場合、`length` の既定は「R から向き先までの距離 − `gap`」を `maxLength` で制限した値。話者の画像に `face` 領域があり、向き先がその上（30 % 広げた範囲）にあれば顔の矩形（髪・ひげ・眼鏡は顔の楕円からはみ出すため）の `gap` 手前で（本体がすでに矩形に重なっていれば楕円の手前で。同じ画像の別のキャラクターのアンカーへ向けるしっぽは、その顔で止めない）、なければ画像の不透明部分（シルエット）の 0.5 bmm 手前で止める。どちらでも止まらない点（顔領域のないアンカーなど、顔の中心を指す点）へは、向き先から顔の半幅（R から向き先までの半分、6 bmm まで）手前で止め、顔に被らないようにする。 本体がトゲ（`spike`）・爆発（`burst`）の場合は、しっぽがトゲに埋もれないよう、この既定の長さを 1.15 倍（6 bmm 以上）にする。トゲ・爆発のしっぽは輪郭のトゲのひとつとして描き、`curl` の既定を `false` にする（`shout`・`scream` の型は `bend`・`sideCurve` も 0）（まっすぐな辺の三角形）。しっぽの先端では輪郭線も先細りにし、0.1 bmm 以下に収める。
4. 中心線 R→T を、`bend` に応じた 2 次ベジェ曲線にする（制御点を中心線の中点から法線方向に `bend` × `length` × 0.5 ずらす）。
5. 辺 A→T と B→T は、中心線に沿って先端へ収束する曲線とし、`sideCurve` に応じて内側へ反らせる。
6. 向き先が本体の内側にある場合は、しっぽを描かず警告（`BALLOON_TAIL_TARGET_INSIDE`）を出す。

同じコマ（ページ直下のレイヤーでは同じページレイヤー群）の他の吹き出し本体にしっぽが重なる場合は、配置・連結の調整後の輪郭に少し余白を加えて回避する。自分と連結先の本体は対象外。くさび・稲妻の幅、一本線の線幅、思考の泡の大きさを含めて判定する。重ならないしっぽの形は変えない。

重なる場合は、近くの付け根、控えめな曲がり、短縮（最短 2 bmm）の順で試す。向き先は変えず、`root`（`auto` 以外）・`length`・`bend` を明示した場合はその値を保ち、残りの自動の項目だけを調整する。スタイルや既定値での明示も同様。重なりを完全に解消する候補だけを採用する。回避できない場合は元のしっぽをそのまま保ち、相手の吹き出し ID を含む `BALLOON_TAIL_CROSSES` を出す。`who` がなく `tail.to` だけを指定した場合も対象となる。

### 6.6.4 本体との合成

1. 本体の輪郭（形状レベルの不規則さを適用済み）としっぽの輪郭を、ポリゴンの和として合成し、1 つの閉じた輪郭にする。
2. 塗りは合成した輪郭で行う。
3. 線は、合成した輪郭をストロークに分解して描く（[9.5](09-hand-drawn.md#95-形状からストロークへの分解)）。しっぽの付け根（凹の角）でストロークを区切り、しっぽの辺は付け根から先端へ向かって描いて先端で抜く。
4. 凹の角でストロークがわずかに突き抜ける場合、吹き出しの内側に入った部分は描かない（ホワイトで修正したように扱う、[9.5.4](09-hand-drawn.md#954-角と閉じ目)）。

`bubbles` の泡は本体と合成せず、それぞれ独立した小さな楕円として描く。軸比は 0.85〜1.0、傾きは泡ごとにランダム。筆圧のある手描きプリセットでは線幅を 0.6〜1.4 倍に変える。

`cloud` の膨らみは頂点を弦方向に ±15 % ずらし、丸みも個別に変える。くぼみは凹角のまま、本文の安全領域は基準の楕円を保つ。筆圧のあるプリセットでは、くぼみの線幅を 0.6 倍、頂点を 1.4 倍にし、継ぎ目を最大 ±0.15bmm ずらす（はみ出し／隙間）。`hand: clean` ではこの筆圧と継ぎ目の変化を加えない。

## 6.7 サイズの決定

### 6.7.1 流れ

1. 本文を組版する（[7](07-text.md)）。行の長さは `maxChars` などの改行の規則に従う。
2. 組版結果から、本文の各行（縦書きでは各列）の矩形の 4 隅の点を求め、`padding` だけ外側へ広げる。ルビ・傍点の範囲も含める。
3. 形状ごとの方法で、これらの点をすべて内側に含む最小の本体を求める（6.7.2）。
4. `minSize`、`maxSize` で制限する。
5. 本文を、本体の本文領域の中央に置き、`textOffset` を加える。

`spike`（`shout`）・`burst`（`scream`）の自動サイズが通常の改行・縮小でも `maxSize` に収まらない場合は、短い列（横書きでは行）で再組版する。既定の `aspectRange` はこの再試行だけ `[1/3.5, 3.5]` に広げ、低いコマでは横の空きを使いつつ、本文から離れた細長い本体を避ける。通常の 4.5 em の行長下限より短い、3・2・1 文字相当の行長も試す。収まる候補のうち、トゲを含む外接矩形の面積が最小のものを選ぶ。すでに収まる吹き出しの形・組版は変えない。

この再試行では、本文に沿う角丸の安全領域を使い、既定の余白だけを縦 0.2 em・横 0.4 em 以下に詰める。トゲの数が自動の場合は 40 本にして、横長の本体の端に大きな単独のくさびができるのを避ける。`shape.depth` が未指定なら、既定の物理長を短くした候補も比較する（`spike` は最小 70%、`burst` は 55%・35%。トゲをなくすことはしない）。判定にはトゲを含む輪郭全体を使い、`minFontScale` は守る。明示した `shape.depth`・縦横比・余白・トゲの数の指定は維持する。固定 `size` または明示した `overflow` がある場合、この追加の再試行は行わない。本文の安全領域そのものが収まらない場合は、従来どおり診断を出す。

### 6.7.2 形状への当てはめ

楕円の場合、本体の中心から見た点 (xᵢ, yᵢ) をすべて含む半径 (a, b) は、次の条件を満たす。

```text
(xᵢ / a)² + (yᵢ / b)² ≤ 1   （すべての i）
```

縦横比 r = a / b を `aspectRange` の範囲で動かし、面積 π·a·b が最小になる r を黄金分割探索で求める（`aspect` を指定した場合はその値に固定する）。r を固定すると b = maxᵢ √((xᵢ / r)² + yᵢ²) で決まる。

この解析解は**初期値**とする。実際の輪郭は、形状レベルの不規則さ（調和成分、`egg`、`squareness`）と `tilt` によって楕円からずれるため、最終的な大きさは次の手順で決める。

1. 初期値の大きさで、形状レベルの不規則さと `tilt` を適用した本文の安全領域（楕円では輪郭そのものを、経路の揺らぎの振幅 `wobble.amplitude` と線幅の半分だけ内側に縮めた形）を作る。
2. すべての点がその内側に入るまで、縦横比を保って縮尺を二分探索で大きくする（入りすぎている場合は小さくする）。許容誤差は 0.05 mm。
3. 不規則さは要素のシードで決まるため、大きさを変えても輪郭の形の比率は変わらない（調和成分の位相と振幅比は大きさに依存しない）。

その他の形状は、形状の定義が提供する「本文の安全領域」（例: `spike` はトゲの付け根を結ぶ内側の形、`cloud` は膨らみのくぼみを結ぶ内側の形）について、同じ方法で縮尺と縦横比を求める。形状の定義が専用の当てはめ関数を持たない場合は、安全領域の内外判定を使った縮尺の二分探索だけで求める。いずれの形状でも、包含の判定は不規則さと `tilt` を適用した後の形で行う（[14.2.2](14-quality.md#1422-不変条件) の不変条件）。

### 6.7.3 固定サイズ

`size` を指定した場合は、本体の大きさを固定し、本文の安全領域の中で組版する。縦書きでは安全領域の高さを列の長さの上限、横書きでは幅を行の長さの上限とする。

### 6.7.4 収まらない場合

| `overflow` | 処理 |
|---|---|
| `grow` | 本体を大きくする。`maxSize` を超える場合は、`shrink` と同じ処理を行い、それでも収まらなければ `maxSize` を超えて大きくし、警告（`BALLOON_TOO_LARGE`）を出す |
| `shrink` | 文字サイズを `minFontScale` まで段階的（元の大きさの 5 % ずつ）に縮める。縮めて収まった場合は情報（`TEXT_SHRUNK`）を出す。それでも収まらなければ `clip` と同じ処理を行う |
| `clip` | はみ出した本文を本体の形で切り、警告（`TEXT_OVERFLOW`）を出す |
| `error` | エラー（`TEXT_OVERFLOW`）にする |

本体のサイズが自動の `say` で、既定の文字サイズ（`defaults.balloon.fontSize` を含む）を使う場合は、`grow` でも文字を縮めない。文節の途中や一文字だけの行を増やさずに改行できる候補を試し、収まらなければ文字サイズを保ったまま本体を広げる。`maxSize` を超えたら吹き出しの ID を含む `BALLOON_TOO_LARGE` を、広げた本体をコマ内に配置できなければ `BALLOON_NO_SPACE` を出す。コマで切り抜かない吹き出しを明示的に配置した場合は、コマ枠をまたぐ位置指定も保つ。個別に文字サイズを指定した吹き出しや、明示的に `overflow: shrink` を選んだ吹き出しは、従来どおり縮小できる。

## 6.8 配置

| 方法 | 指定 | 優先度 |
|---|---|---|
| 座標 | `at`（+ `anchor`、`offset`） | P0 |
| 寄せ | `place`（+ `inset`） | P0 |
| 自動配置 | 位置を指定しない（`dialogue` の行を含む） | P1（6.12） |
| 流し込み | 位置を指定しない（自動配置の実装前、または `autoPlace: flow`） | P0 |

**流し込み**は、位置を指定していない吹き出しを、コマの上端の読み始め側（`readingDirection: rtl` なら右上）から読み方向へ、コマの吹き出しの順序（[6.11](#611-セリフの省略記法dialogue)）で 1 mm の間隔で並べる。コマの幅に収まらなければ下の段に送る。自動配置を実装した後も、`autoPlace: flow`（コマ・ページ・ドキュメントの `defaults.balloon` に書ける）で選べる。

## 6.9 連結と重なり

（P1）

### 6.9.1 連結（connect）

同じ話者の続きのセリフを、吹き出し同士をつないで表す。

```yaml
- balloon: そうか
  id: b1
  at: [70%, 15%]
- balloon: やっぱり君だったのか
  at: [45%, 30%]
  connect: { to: b1, style: neck }
```

| キー | 型 | 既定値 | 説明 |
|---|---|---|---|
| `to` | 吹き出しの ID | 必須 | つなぐ相手 |
| `style` | `neck` \| `overlap` \| `line` | `neck` | `neck` はくびれでつなぐ。`overlap` は重なった本体の輪郭を合成する。`line` は短い線でつなぐ |
| `width` | Length \| % | 小さいほうの本体の短辺の 35 % | `neck` のくびれの幅 |

- `neck`: 2 つの本体の中心を結ぶ線に沿った帯（幅 `width`）を作り、2 つの本体と和を取って 1 つの輪郭にする。輪郭の凹の角でストロークを区切る。
- `overlap`: 2 つの本体の和を取る。本体が重なっていない場合は警告（`BALLOON_CONNECT_DISJOINT`）を出し、`neck` として扱う。
- `line`: 本体の縁同士を結ぶ 1 本の線を描く。
- 連結した吹き出しの本文はそれぞれの本体に置く。連結した吹き出しは、構成する吹き出しの `z` の最大値でまとめて描く。

### 6.9.2 重なり

連結しない吹き出し同士が重なる場合は、`z` が等しければ、**吹き出しの順序で先の吹き出し（先に読む吹き出し）を上に描く**（[4.12](04-pages-and-panels.md#412-描画順)）。先の吹き出しの線はすべて見え、後の吹き出しは先の吹き出しの後ろに隠れる。重なった吹き出しは手前のものから読むという漫画の慣習に合わせる。後の吹き出しを手前にしたい場合は `z` を大きくする。重なりによって本文が隠れる場合は警告（`BALLOON_TEXT_HIDDEN`）を出す。

## 6.10 コマの枠との関係

| 表現 | 指定 |
|---|---|
| 枠にかかる吹き出し（枠線の上に描く） | 既定（`clip: auto`）でコマの間の枠線にかかる場合。外周の辺でも枠線の上に描くには `clip: none` |
| 枠で切れる吹き出し | 既定（`clip: auto`）で枠の外周を越える場合。本文は外周の辺から `max(2.5 bmm, 0.8em)` 内側へ寄せる。すべての辺で切るには `clip: panel`。枠線は吹き出しの上に描かれる |
| コマをまたぐ吹き出し | ページの `layers` に置く、またはコマの `layers` に置いて `coords: page` で配置する |

- 本文が安全領域（[4.1](04-pages-and-panels.md#41-ページの幾何)）の外に出る場合は警告（`TEXT_OUTSIDE_SAFE_AREA`）。
- コマの形で本文（ルビを含む）の字形が切れる場合は、最初に切れる文字を示す警告（`TEXT_CLIPPED`）を出す。吹き出しの輪郭やしっぽだけが切れても警告しない。

## 6.11 セリフの省略記法（dialogue）

（P1）

コマの `dialogue` に、セリフを読み順に並べる。各行は吹き出しに展開する。

```yaml
panels:
  - layers:
      - image: taro-surprised
        id: taro1
      - image: hanako-smile
        id: hanako1
    dialogue:
      - taro: えっ!?
      - hanako: |
          ふふ
          びっくりした？
      - { who: taro, as: think, text: なんでここに…… }
      - { as: narration, text: その日の放課後 }
      - { who: teacher, as: offscreen, from: right, text: 早く帰りなさい！ }
```

| キー | 型 | 説明 |
|---|---|---|
| `<キャラクター ID>: 本文` | - | 省略形。`{ who: <ID>, text: 本文 }` と同じ。`{ taro: えっ!?, as: shout }` のように他のキーと併記できる |
| `who` | キャラクター ID | 話者 |
| `text` | 文字列 | 本文 |
| `as` | 発話の種類 | 既定 `say`。`narration` では話者を省略できる |
| `attach` | コマ枠への密着 | `top-right` / `top-left` / `bottom-right` / `bottom-left` / `top` / `right` / `bottom` / `left` / `none` |
| `from` | `top` \| `right` \| `bottom` \| `left` | `as: offscreen` の話者の方向（`tail.offscreen` に展開する） |
| その他 | 吹き出しのプロパティ | `id`、`at`、`shape`、`fontSize` など、吹き出しのすべてのプロパティを書ける |

画面外の話者の尾は、`offscreen` または吹き出しの `from` で指定した側のコマ枠まで伸ばして切る。`maxLength` では短く止めない。枠に届かない `length` は無視して延長し、`BALLOON_OFFSCREEN_LENGTH_IGNORED` を警告する。尾を描かない場合は `tail: none` を使う。

`as: narration` の箱ネームは、既定で `at` に最も近いコマの角に密着する。`at` がなければ右上に置く。`attach: none` は従来の浮いた配置に戻す。他の吹き出しは `attach` を指定しない限り変わらない。
四辺の指定では、もう一方の軸は `at` の位置を保ち、箱がはみ出ない範囲に収める（`at` なしは右上を基準）。箱の外縁を枠線の内縁に合わせ、枠との間に隙間を作らない。変形コマは表示領域の外接矩形を基準にし、断ち切り辺は仕上がり端に合わせる。手描きの線の揺れや回転は密着を保証しないため、厳密な箱には `hand: clean` と回転なしを使う。密着した箱は自動配置の障害物になる。

- 展開した吹き出しは、コマの `layers` の後ろに、行の順で追加する。ID は `<コマ ID>-d<行の番号>` とする。
- **コマの吹き出しの順序**は、展開した後の `layers` の中の吹き出しの順（`layers` に書いた吹き出し、続いて `dialogue` の行）とする。この順序を、読み順、流し込み・自動配置の処理順、重なりの上下、読み順の検証、セリフ一覧のすべてで使う。
- 位置を指定しない行は、自動配置（6.12）で位置を決める。
- `who` の話者の画像が同じコマにない場合は、しっぽを `direction` の既定値で描き、情報（`DIALOGUE_SPEAKER_NOT_IN_PANEL`）を出す。
- `who` に未定義のキャラクター ID を書いた場合はエラー（`REF_NOT_FOUND`）。

## 6.12 自動配置

### コマ内への収容（contain）

`contain: panel | none` の既定は `panel`。`say`、`think`、`shout`、`scream`、`whisper`、`offscreen`、`aside` を含め、コマに属するすべての吹き出しに適用する。ページの `layers` の吹き出しには適用しない。`defaults.balloon.contain` で作品・ページ・コマ単位に変更できる。

収容には外接矩形でなく、斜め・台形・凹多角形・形状付きコマの輪郭を使う。通常は枠線の半幅 + 0.3 bmm の余白を取り、最も近い収容位置を数値探索する。移動で入らなければ改行を組み直し、それでも入らなければ `minFontScale` まで段階的に文字を縮める。入らない場合は `BALLOON_NO_SPACE` 警告を出す。本文は省略しないが最終クリップでは切れる可能性があるため、コマを広げるかセリフを短くする。

既定の文字サイズを使う自動サイズの `say` は、`overflow: grow` のとき、コマ内への収容でも文字を縮めない。

明示の `at` で本体が辺に接する（許容差 0.6 bmm）・辺を越える場合は、位置を押し戻さず枠で平らに切る。自動配置は本体全体が入る候補を優先し、その候補がないときだけ浅い辺寄せを検討する。切る深さは辺の法線方向の本体寸法の 25% 以下、角では各辺 10% 以下で、角の候補は ellipse / cloud / round-rect に限る。尾の付け根と尾全体、本文の余白がコマ内に残る候補だけを使い、同程度の候補間での優遇は費用 −0.02 にとどめる。本文は切れた辺から `max(2.5 bmm, 0.8em)` 内側へ寄せ、本体にも収める。枠線は吹き出しの上に描く。尾・連結部もコマで切る。`offscreen` の尾は従来どおり枠まで伸ばして切る。

意図的にコマをまたぐ場合は `contain: none`、`bridge: true`、`clip: none`、`clip: { to: panel, open: [...] }` または複数コマへのクリップを指定する。これらは収容と `BALLOON_IN_GUTTER` 警告を無効にする。`bridge: true` は「2 コマを意図的につなぐ」という宣言であり、自動で連結先を作る指定ではない。明示の解除なしで収容されていないインクが間白・他コマに出る場合は `BALLOON_IN_GUTTER` 警告を出す。

```yaml
defaults:
  balloon: { contain: panel }
# 意図的なコマまたぎ:
# - balloon: 次のコマへ
#   bridge: true
```

（P1）

位置を指定していない吹き出しを、読みやすさの規則に従って自動で置く。

### 6.12.1 入力

- 配置領域: コマの表示領域を `autoPlace.inset`（既定 1.5 mm、B5 基準で比例）だけ縮め、安全領域と重ねた矩形。
- 障害物:
  - 位置を明示した吹き出し・地の文字・描き文字（重なりを強く避ける）
  - 画像の素材の領域 `face`、`avoid`（強く避ける）
  - 画像のアンカー `mouth`（覆ってはならない）
  - 画像の外接矩形（弱く避ける）
- 配置する吹き出しの列: コマの吹き出しの順序（6.11）のうち、位置を指定していないもの。

### 6.12.2 手順

1. 吹き出しの大きさを 6.7 で決める。
2. 配置領域に、間隔 `max(1.5 mm, 配置領域の短辺 / 28)` の格子で中心の候補点を作る（寸法は B5 基準で比例）。
3. 列の先頭から順に、各候補点について次の費用を計算する。置いた吹き出しは、以降の吹き出しの障害物になる。1 つずつ最小の候補に決めると、後の吹き出しが読み順を保てる場所を失うことがあるため、途中までの配置を費用の合計の小さい順に 6 通り保持するビーム探索で進める（各配置から、互いに格子間隔の 2.5 倍以上離れた費用の小さい候補を 6 つまで展開する）。最後に合計が最小の配置を採る。

| 費用の項 | `weights` のキー | 内容 | 既定の重み |
|---|---|---|---|
| 読み順 | `order` | 直前の吹き出し（位置を指定したものを含む）との位置関係。直前の吹き出しの下端より下（高さの 15 % の重なりまで許す）にあれば次の段として 0。上下に重なる同じ段にあれば、読み方向に進んでいる（`rtl` なら直前の左端より左。1.5 bmm まで許す）とき 0、戻っている量に応じて 0.15〜1。直前より完全に上にあれば 1 以上 | 120 |
| 上への戻り | `rise` | 同じ段の中で、上端が直前の吹き出しの上端より（配置領域の高さの 4 % を超えて）上にある量。配置領域の高さで正規化 | 30 |
| 流れ | `flow` | 直前の吹き出しのすぐ隣（読み方向に 1.5 bmm 空けた位置）か、次の段の先頭（読み始めの辺に寄せ、直前の下端の下）のうち近い方からの距離。配置領域の対角線で正規化 | 3 |
| 読み始め | `start` | 先頭の吹き出しの、読み始めの角（`rtl` なら右上）からの距離 | 4 |
| 重なり | `overlap` | 他の吹き出し・文字との重なりの面積の比。吹き出し・文字・擬音の矩形は 2 bmm 広げて測り（吹き出しどうしは広げた部分を 0.3 倍で数える）、くっつき過ぎを避ける | 50 |
| 回避領域 | `avoid` | `face`、`avoid` との重なりの比。`face` は外接矩形に内接する楕円（12 % 広げる）として測る。`mouth` を覆う場合は 1000 | 60 |
| 人物 | `figure` | キャラクターの画像の不透明な部分（シルエット）を覆う比 | 25 |
| 組み替え | `reshape` | 行の長さを変えた組み方（下記）を使う場合に加える | 3 |
| 話者との距離 | `speaker` | 話者のアンカーとの距離が、吹き出しの半径の 1.6 倍から離れるほど大きい | 1.5 |
| しっぽ | `tail` | 話者へのしっぽの経路が、置いた吹き出しと交わるごとに加える | 4 |
| 上寄せ | `top` | 中心の y の正規化値（上ほど小さい） | 1 |
| はみ出し | `outside` | 配置領域の外に出る面積の比 | 30 |
| 画面外の話者 | `offscreen` | 画面外の話者（`tail.offscreen`）の側の辺から離れる距離の比 | 8 |

4. 同点の候補は、読み始めの角に近い順（`rtl` では上、次に右）で選ぶ。
4'. `maxChars` を指定していない吹き出しは、元の組み方に加えて、1 行（列）の文字数を 0.6 倍と 1.5 倍にした組み方も候補にし、すべての組み方の候補点を同じビームで比べる（`autoPlace.reshape: false` で無効）。狭いコマで、人物を覆う代わりに頭の横の細い隙間に収められるようにする。
5. 採った配置で、吹き出しの費用がしきい値（`autoPlace.threshold`、既定 25）を超える場合は、警告（`BALLOON_NO_SPACE`）を出す（文字サイズを縮めての再試行は今後の拡張）。

重みとしきい値は `defaults.balloon.autoPlace.weights`、`autoPlace.threshold` で変更できる。結果は決定的でなければならない。

### 6.12.3 読み順の検証

自動配置か手動配置かにかかわらず、1 つのコマの中の吹き出しについて、コマの吹き出しの順序（6.11）と位置から推定した読み順が食い違う場合は、情報（`BALLOON_ORDER_MISMATCH`）を出す。推定は、自動配置の読み順の項（6.12.2）と同じ段の規則を、リストで隣り合う吹き出しの外接矩形に適用し、重み 1 として 0.3 を超えるものを食い違いとする（`connect` で連結した側の吹き出しは除く）。

layers:

## 6.14 検証

最終配置で、本体の外接矩形が縦横とも 1 bmm を超えて重なる場合は `BALLOON_OVERLAP` を警告する（しっぽは含めない）。同じコマの全ペアで、後の吹き出しの中心が 1 bmm を超えて上、かつ右側または同じ横位置（`readingDirection: ltr` では左側）なら `BALLOON_READING_ORDER` を警告する。重なるペアでは、同じ高さで読み始め側に 1 bmm を超えて寄っている場合も対象になる。コマをまたぐペアは重なる場合だけ読み順を確認する。手動配置・自動配置の両方が対象で、連結した両端、`aside`、本体のない `shape: none` は除外する。警告には両方の ID とコマを含める。既存の情報診断や本文の被覆診断はそのまま残る。

| コード | 重大度 | 条件 |
|---|---|---|

| `BALLOON_TAIL_TARGET_INSIDE` | 警告 | しっぽの向き先が本体の内側にある |
| `BALLOON_TAIL_SHORT` | 警告 | 吹き出しが話者から遠く、しっぽの先端が話者まで 20 bmm 以上届かない。吹き出しを話者へ寄せる |
| `BALLOON_TAIL_CROSSES` | 警告 | 自動調整後もしっぽが他の吹き出し本体と重なる。相手の ID を通知 |
