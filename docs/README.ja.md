# mangacli 仕様書

mangacli は、漫画の構造を YAML（または TypeScript オブジェクト）で宣言すると、日本の漫画として完成した画像（白黒・カラー）をレンダリングして出力する TypeScript 製の npm ライブラリ兼 CLI である。ライセンスは MIT。

本ディレクトリは、その仕様書一式を収める。実装者・ドキュメント執筆者・利用者が同じ前提で議論できるように、機能・データ形式・描画アルゴリズム・API・CLI・検証・品質基準・開発計画を網羅する。

## 表記規約

### 要求レベル

| 表記 | 意味 |
|---|---|
| 〜しなければならない（MUST） | 必須。満たさない実装は仕様不適合 |
| 〜すべきである（SHOULD） | 推奨。合理的な理由がある場合のみ逸脱してよい。逸脱した場合は文書化する |
| 〜してもよい（MAY） | 任意 |

### 優先度

各機能には優先度を付ける。マイルストーンとの対応は [15-roadmap.md](15-roadmap.md) を参照。

| 優先度 | 意味 |
|---|---|
| **P0** | 最小リリース（MVP）に必須 |
| **P1** | v1.0 までに実装 |
| **P2** | v1.0 以降の拡張候補。データ形式上の予約のみ行う場合がある |

優先度の表記がない項目は、それを含む節の優先度に従う。

### 既定値の数値

寸法・手描きのパラメータ・網点化の変換などの**数値の既定値は暫定値**である。M1 の実装中にサンプルを作りながら調整し、確定した値を `engine: 1` として固定する（[15.2](15-roadmap.md#152-決定事項) の D-24）。

### その他

- 長さの例は、特記がない限り B5 判（182 × 257 mm）を前提とする。
- YAML の例は説明に必要な部分だけを抜き出している。省略箇所は `...` で示す。
- 「要素」は、コマやページに置く描画対象（画像、吹き出し、文字、効果など）を指す。詳細は [01-overview.md の用語集](01-overview.md#17-用語集) を参照。
- 仕様書の本文は日本語で書く。各ディレクトリの README は英語版を既定とし、日本語版（`README.ja.md`）を併置する。
