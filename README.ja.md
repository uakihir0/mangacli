# mangacli

mangacli は、漫画の構造を記述したデータから、日本の漫画のページを描画するツールです。コマ割り、吹き出し、セリフ、効果を YAML（または同じ構造の TypeScript オブジェクト）で書くと、完成したページの画像を白黒またはカラーで出力します。

キャラクターや背景などの絵は、画像ファイルとして用意します。それ以外のもの（コマの枠線、吹き出し、写植、描き文字、集中線などの効果線、スクリーントーン、漫符）は mangacli が描きます。どれも**ペンで描いたように**描きます。吹き出しはわずかに揺らぎ、線は筆圧で太さが変わって入り抜きがあり、閉じた輪郭はぴったりとは閉じません。

> **状況:** 仕様策定の段階です。まだ何も実装していません。仕様書は [docs/](docs/README.ja.md) にあります。

## 予定している機能

- 日本の漫画の慣習を既定にする: 右から左の読み順、縦書き、アンチゴチ、ルビ、縦中横、禁則処理、間白、断ち切り、ノンブル、トンボ。
- さまざまな吹き出し: 楕円、思考の雲、叫びのトゲ、震え、小声（破線）、ナレーションの四角、電子音など。しっぽはキャラクターに自動で向く。
- 効果: 集中線、ベタフラッシュ、ウニフラッシュ、流線、縦線、カケアミ、スクリーントーン（網点・万線・砂目・グラデーション）。
- 出力: PNG・JPEG・WebP（PDF・SVG・TIFF は v1.0 で対応予定）。カラー、グレースケール、印刷用の 2 値（塗り足し付き）。
- 決定的: 同じ入力からは常に同じ出力になる。シードを変えると「描き直した」別の線になる。
- 和文フォントは、同梱のカタログ（SIL OFL のフォント）から必要なときに取得するため、フォントを用意しなくても描画できる。
- CLI と TypeScript API の両方を提供する。

## 書き方の例

```yaml
mangacli: 1

assets:
  taro: ./assets/taro.png

pages:
  - layout:
      rows: [[1], [1, 1]]
    panels:
      - layers:
          - image: taro
          - balloon: おはよう
      - layers:
          - balloon: |
              今日は
              いい天気だね
      - layers:
          - effect: focus-lines
          - text: その時——
            place: top-right
```

```bash
npx mangacli render manga.yaml --profile print-mono
```
